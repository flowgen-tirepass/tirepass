## 🎯 프로젝트 개요

### 배경
- 기존 시스템: Firebird 기반 ERP (오프라인 전화주문)
- 문제점: 수동 주문, 재고 확인 어려움, 고객 불편
- 목표: 24시간 온라인 주문 가능한 모바일 쇼핑몰 구축

### 핵심 과제
1. **ERP 실시간 연동**: Firebird DB → FastAPI → Django
2. **복잡한 할인 정책**: 브랜드별, 고객별, DOT별, 연식별 할인
3. **재고 관리**: ERP 동기화 + DOT 연식별 재고 배정
4. **모바일 최적화**: B2B 고객 대상 간편한 UX
5. **결제 시스템**: 토스페이먼츠 연동 (카드/계좌)

##### 1. Goods 테이블 중복 레코드 문제 해결
- **문제**: ERP 동기화 시 중복 레코드 생성
- **원인**: CODE를 PK로 사용하지 않고 id 컬럼 사용
- **해결**: CODE를 PK로 변경 + 중복 제거 스크립트

```python
# remove_duplicate_goods.py
duplicates = Goods.objects.values('code').annotate(
    count=Count('code')
).filter(count__gt=1)

for dup in duplicates:
    items = Goods.objects.filter(code=dup['code'])
    keep = items.first()
    items.exclude(pk=keep.pk).delete()
```

## 🎓 배운 점 (Lessons Learned)

### 1. AI 기반 개발의 강점
- **빠른 프로토타이핑**: 아이디어 → 코드 < 1시간
- **에러 해결**: 로그 분석 및 수정 자동화
- **문서화**: 커밋 메시지 자동 생성

### 2. 반복적 개선의 중요성
- OCR 기능처럼 실패한 기능도 학습 경험
- 331개 커밋 = 331번의 개선 기회
- 완벽한 1차 시도보다 빠른 반복이 효과적

### 3. 사용자 중심 개발
- 복잡한 기술 < 간단한 UX
- B2B 고객은 속도와 정확성 우선
- 불필요한 기능 제거도 용기

### 4. 레거시 시스템 통합
- Firebird(1990년대) ↔ Django(2024) 연동 성공
- FastAPI를 중간 계층으로 활용
- 기존 ERP 데이터 최대한 활용
