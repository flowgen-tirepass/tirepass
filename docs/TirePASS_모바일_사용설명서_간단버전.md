## 1. 로그인

### 1.1 회원가입
1. https://tirepass.pythonanywhere.com/mobile/signup/ 접속
2. 정보 입력:
   - 사업자등록번호 (하이픈 없이)
   - 상호명
   - 대표자명
   - 연락처
   - 비밀번호
3. 가입 완료 후 관리자 승인 대기

### 1.2 로그인
1. https://tirepass.pythonanywhere.com/mobile/login/ 접속
2. 사업자등록번호 + 비밀번호 입력
3. 로그인 완료

## 2. 메뉴 구조

### 2.1 하단 네비게이션 바
- **홈**: 대시보드 (빠른 접근)
- **상품**: 상품 검색 및 목록
- **장바구니**: 장바구니 내역
- **주문내역**: 나의 주문 내역
- **내정보**: 프로필 및 설정

## 3. 주요 기능

### 3.1 상품 검색
**위치**: 상품 메뉴 또는 홈 화면

**검색 방법**:
1. 검색창에 키워드 입력
   - 상품명 (예: P ZERO)
   - 상품코드 (예: P-PZERO-25)
   - 타이어 사이즈 (예: 255/40R20)
2. 검색 버튼 클릭
3. 결과 목록 표시

**필터링**:
- 브랜드별 필터
- 재고있는 상품만
- 가격대별 정렬

---

### 3.2 상품 상세

**기능**:
- 상품 정보 확인
- 할인가 확인
- 할인 상세 내역 보기 (4가지 할인)
- DOT(제조년도) 선택
- 수량 선택
- 장바구니 담기
- 견적서 생성

**할인 상세 보기**:
- "할인 상세 보기 ▼" 버튼 클릭
- 4가지 할인 내역 표시:
  1. 기본 할인
  2. 브랜드/그룹 할인
  3. 추가 할인
  4. DOT 할인

---

### 3.3 장바구니

**기능**:
- 장바구니 상품 목록
- 수량 변경
- 상품 삭제
- 선택 주문 / 전체 주문
- 총 금액 자동 계산

**주문 프로세스**:
1. 장바구니에서 상품 확인
2. 수량 조정
3. "주문하기" 버튼 클릭
4. 배송지 선택/입력
5. 결제 수단 선택
6. 주문 확인
7. 주문 완료

---

### 3.4 견적서 생성

**방법 1: 상품 상세에서**
1. 상품 상세 페이지
2. DOT 선택 (선택사항)
3. 수량 입력
4. "견적서 생성" 버튼 클릭
5. 마진율 입력 (기본값 자동 설정)
6. "견적 계산하기" 버튼
7. 견적서 확인

**방법 2: 견적 메뉴에서**
1. 견적 메뉴 이동
2. 상품 검색 및 선택
3. DOT 선택 (선택사항)
4. 수량 입력
5. 마진율 입력
6. 견적 계산
7. 견적서 확인 및 인쇄

**견적서 내용**:
- 고객 제안가 (큰 글씨)
- 상품 정보 (상품명, 브랜드, 수량, DOT)
- 매입 정보 (정가, 할인율, 매입가)
- 판매 정보 (매입가, 마진율, 제안가)
- 할인 상세 (4가지 할인 내역)
- 인쇄 기능

---

### 3.5 주문 내역

**기능**:
- 나의 주문 목록
- 주문 상태 확인 (접수, 처리중, 배송중, 완료)
- 주문 상세 보기
- 재주문 기능

**주문 상세**:
- 주문 번호
- 주문 날짜
- 주문 상품 목록
- 결제 금액
- 배송지 정보
- 주문 상태

---

### 3.6 내 정보

**기능**:
- 프로필 정보 확인
- 비밀번호 변경
- 배송지 관리
- 기본 마진율 확인
- 로그아웃

## 4. 주요 작업 프로세스

### 4.1 상품 주문하기
```
1. 상품 검색
   ↓
2. 상품 선택 (상품 상세 확인)
   ↓
3. DOT 선택 (선택사항)
   ↓
4. 수량 입력
   ↓
5. 장바구니 담기
   ↓
6. 장바구니에서 확인
   ↓
7. 주문하기
   ↓
8. 배송지 입력
   ↓
9. 결제 수단 선택
   ↓
10. 주문 완료
```

### 4.2 견적서 만들기
```
1. 상품 상세 또는 견적 메뉴
   ↓
2. 상품 선택
   ↓
3. DOT 선택 (선택사항)
   ↓
4. 수량 입력
   ↓
5. 마진율 입력 (기본값 자동)
   ↓
6. 견적 계산
   ↓
7. 견적서 확인
   ↓
8. 인쇄 또는 저장
```

### 4.3 재주문하기
```
1. 주문 내역 메뉴
   ↓
2. 과거 주문 선택
   ↓
3. "재주문" 버튼 클릭
   ↓
4. 장바구니에 자동 추가
   ↓
5. 수량 조정
   ↓
6. 주문하기
```

## 5. 가격 및 할인 이해하기

### 5.1 가격 구조
```
정가 (공장도가)
  ↓ (-기본 할인)
  ↓ (-브랜드/그룹 할인)
  ↓ (-추가 할인)
  ↓ (-DOT 할인)
매입가 (할인 적용가)
  ↓ (+마진)
고객 제안가
```

### 5.2 할인 종류

#### 1. 기본 할인
- 상품별 기본 할인율
- 관리자가 상품별로 설정
- 예: 피렐리 타이어 20% 기본 할인

#### 2. 브랜드/그룹 할인
- 고객별로 설정된 브랜드 할인
- 예: A 카센터는 피렐리 P ZERO 시리즈 4% 할인
- 자동으로 패턴 매칭되어 적용

#### 3. 추가 할인
- 특정 고객에게 특정 상품 추가 할인
- 예: VIP 고객에게 특정 상품 5% 추가 할인

#### 4. DOT 할인
- 제조년도별 할인
- 2024년: 3%
- 2023년: 4%
- 2022년: 5%
- 2021년 이전: 10%

### 5.3 마진 계산
- 마진율: 매입가 대비 추가 이익률
- 계산식: `고객 제안가 = 매입가 × (1 + 마진율/100)`
- 예: 매입가 100,000원, 마진율 15%
  - 제안가 = 100,000 × 1.15 = 115,000원

## 6. 화면별 설명

### 6.1 홈 화면
- 빠른 접근 버튼
  - 상품 검색
  - 견적서 생성
  - 주문 내역
- 최근 본 상품
- 자주 주문하는 상품
- 공지사항

### 6.2 상품 목록
- 상품 카드 형태
  - 상품 이미지 (브랜드 로고)
  - 상품명
  - 브랜드
  - 할인가 (큰 글씨)
  - 재고 수량
- 무한 스크롤 (자동 로드)

### 6.3 상품 상세
- 상품 정보
  - 상품명
  - 브랜드
  - 상품코드
  - 재고 수량
- 가격 정보
  - 공장도가 (취소선)
  - 매입가 (할인 적용) (큰 글씨, 파란색)
  - 할인율 배지 (빨간색)
  - 할인 상세 보기 버튼
- DOT 선택 (드롭다운)
- 수량 입력
- 버튼
  - 견적서 생성 (녹색)
  - 장바구니 담기 (파란색)

### 6.4 장바구니
- 상품 목록
  - 상품 정보 (이름, 코드, DOT)
  - 단가
  - 수량 조정 버튼
  - 삭제 버튼
- 하단 요약
  - 총 상품 수
  - 총 금액
  - 주문하기 버튼

### 6.5 견적서
- 최상단: 고객 제안가 (큰 글씨, 보라색 배경)
- 상품 정보 테이블
- 가격 상세
  - 매입 정보 (회색 배경)
  - 판매 정보 (녹색 배경)
- 할인 상세 테이블
- 인쇄 버튼

### 6.6 주문 내역
- 주문 카드 형태
  - 주문 번호
  - 주문 날짜
  - 주문 상태 (배지)
  - 총 금액
  - 상품 요약
- 상세 보기 버튼
- 재주문 버튼

## 7. 자주 묻는 질문 (FAQ)

### Q1. 회원가입 후 로그인이 안 돼요.
**A**: 관리자 승인이 필요합니다. 가입 후 영업일 기준 1일 이내 승인 처리됩니다.

### Q2. 할인가가 다르게 표시돼요.
**A**: 고객별로 할인율이 다르게 설정되어 있습니다. 관리자에게 문의하세요.

### Q3. DOT를 꼭 선택해야 하나요?
**A**: 선택사항입니다. DOT를 선택하지 않으면 DOT 할인이 적용되지 않습니다.

### Q4. 견적서를 저장할 수 있나요?
**A**: 현재는 인쇄 기능만 제공됩니다. 브라우저 인쇄 기능으로 PDF 저장 가능합니다.

### Q5. 재고가 없는 상품도 주문할 수 있나요?
**A**: 시스템상 주문은 가능하지만, 관리자가 확인 후 연락드립니다.

### Q6. 마진율은 어떻게 설정하나요?
**A**: 관리자가 고객별 기본 마진율을 설정합니다. 견적서 생성 시 조정 가능합니다.

### Q7. 결제는 어떻게 하나요?
**A**: 현재는 주문 접수 후 별도 결제 진행합니다. (계좌이체, 카드결제 등)

### Q8. 주문을 취소하고 싶어요.
**A**: 주문 상태가 "접수"일 때는 관리자에게 연락하여 취소 요청하세요.

## 8. 팁

### 8.1 빠른 검색
- 타이어 사이즈로 검색할 때 슬래시(/) 없이 숫자만 입력
- 예: 255/40R20 → 2554020 입력

### 8.2 장바구니 활용
- 여러 상품을 비교할 때 장바구니에 먼저 담기
- 수량 조정은 장바구니에서 한 번에

### 8.3 견적서 활용
- 고객에게 제시할 가격은 견적서로 생성
- 마진율을 다양하게 조정하여 여러 견적 생성 가능

### 8.4 재주문 활용
- 자주 주문하는 상품은 주문 내역에서 재주문 기능 사용
- 시간 절약 가능

## 9. 주의사항

### 9.1 가격 정보
- 표시된 가격은 실시간 ERP 가격입니다.

- 로그인 정보를 타인과 공유하지 마세요.
