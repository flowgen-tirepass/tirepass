# TirePASS 관리자 사용설명서 (간단 버전)

---

## 1. 로그인

### 1.1 접속
- **URL**: https://tirepass.pythonanywhere.com/admin/
- **ID**: 관리자 계정 사용자 이름 (예: admin, staff_user 등)
- **PW**: 설정한 비밀번호

**주의사항**:
- **사업자등록번호는 관리자 페이지 접속 불가**
- 사업자등록번호는 모바일 페이지 로그인용입니다.
- 관리자 페이지는 Django 슈퍼유저 또는 스태프 계정만 접속 가능합니다.

---

## 2. 메뉴 구조

### A. 판매 (8개 메뉴)

#### 1. 상품 관리 (Goods)
- **기능**: ERP 실시간 상품 조회 및 할인율 설정
- **주요 작업**:
  - 상품 검색 (코드, 이름, 브랜드)
  - 타이어 사이즈 검색 (예: 2355519 입력 시 자동 변환)
  - 필터링 (타이어만, 재고있음, 브랜드별)
  - 기본 할인율 일괄 적용 (22%, 25%, 30%)

#### 2. 모바일 주문 (MobileOrder)
- **기능**: 고객이 모바일에서 주문한 내역 관리
- **주요 작업**:
  - 주문 상태 변경 (접수 → 처리중 → 배송중 → 완료)
  - 주문 상세 확인 (주문 항목, 결제 정보)
  - 합계 금액 자동 계산

#### 3. ERP 전화 주문 (ERPPhoneOrder)
- **기능**: 전화로 받은 주문을 수동 입력
- **주요 작업**:
  - 주문 생성 (고객 정보 + 상품 정보)
  - 할인율 자동 적용
  - 주문 번호 자동 생성 (ERP-YYYY-NNN)

#### 4. 주문 항목 (OrderItem)
- **기능**: 주문별 상품 상세 내역 조회
- **주요 작업**:
  - 주문 항목 검색 (주문번호, 상품코드)
  - 할인 적용 내역 확인

#### 5. 결제 (Payment)
- **기능**: 결제 정보 및 이력 관리
- **주요 작업**:
  - 결제 상태 확인 (대기, 완료, 취소)
  - 결제 수단별 조회
  - 결제 취소 처리

#### 6. 장바구니 (ShoppingCart)
- **기능**: 고객의 임시 장바구니 내역
- **주요 작업**:
  - 장바구니 상품 확인
  - 미결제 장바구니 관리

#### 7. 배송지 (ShippingAddress)
- **기능**: 고객별 배송지 정보 관리
- **주요 작업**:
  - 배송지 등록/수정/삭제
  - 기본 배송지 설정

#### 8. 고객 (Customers)
- **기능**: 회원 정보 관리
- **주요 작업**:
  - 고객 검색 (코드, 이름, 사업자번호)
  - 회원가입 승인
  - 개별 상품 할인 개수 확인

---

### B. 할인 (6개 메뉴)

#### 1. 브랜드 그룹 (BrandGroup)
- **기능**: 브랜드별 시리즈 그룹 관리
- **주요 작업**:
  - 브랜드 그룹 생성/수정/삭제
  - 패턴 등록 (시리즈명)
  - 그룹 활성화/비활성화
  - **전체 고객 일괄 할인 적용** ← 가장 많이 사용
  - 그룹 복제 기능

**[중요] 일괄 할인 적용 방법**:
1. 적용할 그룹 선택 (체크박스)
2. 액션 선택: "선택한 그룹의 할인율을 전체 고객에게 적용"
3. 실행 버튼 클릭
4. 할인율 입력 (예: 4.0)
5. "할인율 적용" 버튼 클릭
6. 결과 확인 (신규 X건, 수정 Y건)

#### 2. 브랜드 그룹 패턴 (BrandGroupPattern)
- **기능**: 상품명 패턴 규칙 관리
- **주요 작업**:
  - 패턴 등록 (예: "P ZERO", "PILOT SPORT")
  - 패턴별 그룹 연결
  - 패턴 삭제

#### 3. 고객 할인 (CustomerDiscount)
- **기능**: 고객별 브랜드/그룹 할인율 관리
- **주요 작업**:
  - 고객별 할인율 조회
  - 할인율 직접 수정 (리스트에서 바로 수정 가능)
  - 할인 활성화/비활성화
  - 적용 기간 설정

#### 4. 고객 상품 추가 할인 (CustomerProductDiscount)
- **기능**: 특정 고객에게 특정 상품 추가 할인
- **주요 작업**:
  - 개별 상품 할인 등록
  - 할인율 직접 수정
  - 우선순위 설정

#### 5. 연식 재고 관리 (YearAllocation)
- **기능**: DOT(제조년도)별 재고 및 할인율 설정
- **주요 작업**:
  - 연도별 재고 수량 입력
  - 연도별 할인율 설정 (2024년: 3%, 2023년: 4%, 2022년: 5%, 2021년 이전: 10%)
  - 재고 수량 자동 집계

#### 6. 할인 이력 (DiscountHistory)
- **기능**: 할인 적용 이력 조회
- **주요 작업**:
  - 거래별 할인 내역 확인
  - 날짜별 조회
  - 통계 분석

---

### C. 설정 (8개 메뉴)

#### 1. 상품 표시명 (GoodsDisplayName)
- **기능**: 상품명 한글/영문 표시명 설정
- **주요 작업**:
  - 상품별 한글명 설정
  - 상품별 영문명 설정
  - 모바일 화면 표시명 관리

#### 2. 성능 카테고리 (PerformanceCategory)
- **기능**: 타이어 성능 카테고리 관리
- **주요 작업**:
  - 카테고리 생성 (예: 드라이 성능, 웨트 성능)
  - 카테고리별 아이콘 설정

#### 3. 성능 태그 (PerformanceTag)
- **기능**: 타이어 성능 태그 관리
- **주요 작업**:
  - 태그 생성 (예: A+, A, B)
  - 카테고리별 태그 분류

#### 4. 상품 성능 태그 (GoodsPerformanceTag)
- **기능**: 상품별 성능 태그 연결
- **주요 작업**:
  - 상품에 성능 태그 할당
  - 성능 정보 표시

#### 5. ERP 스냅샷 (ERPSnapshot)
- **기능**: ERP 연동 상태 모니터링
- **주요 작업**:
  - 연동 상태 확인 (정상/장애)
  - 응답 시간 확인
  - 에러 로그 조회

#### 6. 실시간 재고 스냅샷 (GoodsRealtimeSnapshot)
- **기능**: 재고 변화 추적
- **주요 작업**:
  - 재고 증감 내역 확인
  - 시간대별 재고 변화 분석

#### 7. 사용자 (User)
- **기능**: 관리자 계정 관리
- **주요 작업**:
  - 관리자 계정 생성
  - 비밀번호 변경
  - 권한 설정

#### 8. 활동 로그 (LogEntry)
- **기능**: 관리자 활동 이력
- **주요 작업**:
  - 작업 내역 조회 (추가, 수정, 삭제)
  - 날짜별 조회
  - 사용자별 조회

## 3. 주요 작업 프로세스

### 3.1 신규 고객 할인율 설정
1. **브랜드 그룹** 메뉴 이동
2. 적용할 브랜드 그룹 선택
3. 액션: "선택한 그룹의 할인율을 전체 고객에게 적용"
4. 할인율 입력 후 적용

### 3.2 특정 고객 개별 할인 설정
1. **고객 상품 추가 할인** 메뉴 이동
2. "추가" 버튼 클릭
3. 고객코드, 상품코드, 할인율 입력
4. 저장

### 3.3 주문 처리
1. **모바일 주문** 또는 **ERP 전화 주문** 메뉴 이동
2. 주문 선택
3. 주문 상태 변경
4. 저장

### 3.4 상품 기본 할인율 일괄 적용
1. **상품 관리** 메뉴 이동
2. 필터링 (예: 피렐리 브랜드만)
3. 상품 선택 (체크박스)
4. 액션: "선택한 상품의 할인율을 25%로 설정"
5. 실행

## 4. 자주 사용하는 기능

### 4.1 상품 검색
- **일반 검색**: 상품명, 코드, 브랜드명 입력
- **타이어 사이즈 검색**: 숫자만 입력 (예: 2355519)
  - 자동 변환: 235/55R19

### 4.2 필터링
- **타이어만 보기**: "타이어만" 필터 체크
- **재고있는 상품만**: "재고있음" 필터 체크
- **브랜드별**: 우측 사이드바에서 브랜드 선택

### 4.3 할인율 직접 수정
- **고객 할인** 또는 **고객 상품 추가 할인** 메뉴에서:
  - 리스트에서 할인율 칸 클릭
  - 숫자 입력
  - 하단 "저장" 버튼 클릭

### 4.4 주문 상세 확인
- 주문 번호 클릭 → 상세 페이지
  - 주문 항목: 상품, 수량, 가격
  - 결제 정보: 결제 수단, 금액, 상태
  - 배송 정보: 배송지, 배송 상태

---

## 5. 주의사항

### 5.1 할인율 설정
- 할인율은 0~100 사이의 숫자
- 소수점 2자리까지 입력 가능
- 일괄 적용 시 기존 할인율 덮어쓰기 됨

### 5.2 상품 관리
- ERP 실시간 데이터이므로 저장 불가
- 할인율만 별도 관리 (YearAllocation 테이블)

### 5.3 주문 처리
- 주문 상태는 순서대로 변경 권장
- 취소 시 재고 자동 복구 안 됨 (수동 처리)

### 5.4 권한
- 슈퍼유저만 전체 메뉴 접근 가능
- 일반 스태프는 제한된 메뉴만 접근
