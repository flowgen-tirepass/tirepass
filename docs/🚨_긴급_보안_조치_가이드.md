## ⚠️ 즉시 수행해야 할 작업 (우선순위)

### 1단계: 토스페이먼츠 키 즉시 폐기 및 재발급 (최우선) 🔥

**왜 긴급한가?**
- GitHub는 공개 저장소이므로 누구나 키를 볼 수 있음
- 악의적 사용자가 키를 복사하여 무단 결제 시도 가능
- 토스페이먼츠 라이브 키는 실제 결제에 사용됨

**즉시 조치**:

1. **토스페이먼츠 개발자센터 접속**
   - https://developers.tosspayments.com/ 로그인

2. **기존 키 폐기**
   - 내 개발정보 → API 키
   - 라이브 환경 탭
   - **"키 재발급"** 또는 **"키 폐기"** 버튼 클릭
   - 기존 키가 즉시 무효화됨

3. **새 키 발급**
   - 새로운 클라이언트 키 (live_ck_로 시작)
   - 새로운 시크릿 키 (live_sk_로 시작)
   - 새로운 보안 키
   - **메모장에 안전하게 복사**

4. **PythonAnywhere 환경변수 즉시 업데이트**
   - Web 탭 → Environment variables
   - TOSS_PAYMENTS_CLIENT_KEY 값 교체
   - TOSS_PAYMENTS_SECRET_KEY 값 교체
   - TOSS_PAYMENTS_SECURITY_KEY 값 교체
   - **Reload** 버튼 클릭

- `docs/🎯_PythonAnywhere_환경변수_최종.txt` - 모든 키 포함
- `docs/환경변수_간단버전_API추가.txt` - 모든 키 포함

## 🔍 Git 히스토리에서 완전히 제거하기 (선택 사항)

**주의**: 이 작업은 복잡하고 위험할 수 있습니다.

커밋 히스토리에서 민감한 정보를 완전히 제거하려면:

### 방법 1: git filter-repo 사용 (권장)

```bash
# 1. git-filter-repo 설치
pip install git-filter-repo

# 2. 백업 생성
cd C:\Users\jmyang\Dropbox\1.0_tirepass
git clone . ../tirepass_backup

# 3. 민감한 파일 히스토리에서 제거
git filter-repo --path docs/환경변수_최종버전_UTF8.md --invert-paths
git filter-repo --path docs/🎯_PythonAnywhere_환경변수_최종.txt --invert-paths
git filter-repo --path docs/환경변수_간단버전_API추가.txt --invert-paths

# 4. 강제 푸시
git push origin main --force
```

### 방법 2: GitHub에 요청

1. GitHub Support에 연락
2. 저장소 캐시 삭제 요청
3. https://github.com/github/docs/issues/new?template=remove-sensitive-data.yml

## 🛡️ 향후 예방 조치

### 1. 민감한 정보는 절대 Git에 커밋하지 않기

**올바른 방법**:
- 환경변수는 PythonAnywhere에서만 설정

- 문서에는 예시 값만 표기

**예시**:
```

TOSS_PAYMENTS_CLIENT_KEY=live_ck_jExPeJWYVQ1zDYG7N7PEV49R5gvN
```
