## 1. 시작하기

### 1.1 타이어패스란?

타이어패스는 타이어를 쉽고 빠르게 구매할 수 있는 모바일 주문 플랫폼입니다.

**주요 기능**:
- 다양한 브랜드의 타이어 실시간 검색
- 간편한 장바구니 및 주문
- 안전한 결제 (토스페이먼츠)
- 간편결제 지원 (카카오페이, 네이버페이, 토스페이 등)
- 포인트 적립 및 사용
- 주문 내역 조회

### 1.2 앱 접속

**웹 브라우저로 접속**:
- URL: `http://your-domain.com/mobile/`
- 인트로 화면에서 "시작하기" 클릭

**PWA(Progressive Web App) 설치** (선택):
1. 모바일 브라우저에서 접속
2. 브라우저 메뉴에서 "홈 화면에 추가" 선택
3. 앱처럼 사용 가능

### 1.3 시스템 요구사항

- **모바일**: iOS Safari, Android Chrome 최신 버전
- **태블릿**: iPad, Android 태블릿 지원
- **인터넷 연결**: 안정적인 모바일 데이터 또는 Wi-Fi

## 2. 회원가입 및 로그인

### 2.1 회원가입

#### 2.1.1 회원가입 시작
1. 인트로 화면 또는 홈 화면에서 "회원가입" 클릭
2. 회원가입 양식 작성

#### 2.1.2 필수 정보 입력
- **고객코드**: 기존 거래 고객의 경우 ERP 고객코드 입력
- **사용자 이름**: 로그인에 사용할 ID
- **비밀번호**: 8자 이상, 안전한 비밀번호 설정
- **비밀번호 확인**: 동일한 비밀번호 재입력
- **이메일**: 유효한 이메일 주소
- **연락처**: 휴대폰 번호 (예: 010-1234-5678)

#### 2.1.3 약관 동의
- **이용약관** 동의 (필수)
- **개인정보처리방침** 동의 (필수)
- 각 약관을 클릭하여 내용 확인 후 동의

#### 2.1.4 결제 방식 안내
- 주문시 토스페이먼츠 결제 위젯을 통해 결제합니다
- 카카오페이, 네이버페이 등 다양한 간편결제를 이용할 수 있습니다
- 별도의 사전 카드 등록은 필요하지 않습니다

#### 2.1.5 가입 완료
- "가입하기" 버튼 클릭
- 자동으로 로그인되어 홈 화면으로 이동

### 2.2 로그인

#### 2.2.1 로그인 방법
1. 홈 화면에서 "로그인" 클릭
2. 사용자 이름과 비밀번호 입력
3. "로그인" 버튼 클릭

#### 2.2.2 로그인 상태 유지
- 로그인 상태는 자동으로 유지됩니다
- 브라우저를 닫아도 로그인 상태가 보존됩니다

### 2.3 비밀번호 변경

#### 2.3.1 비밀번호 변경 방법
1. 로그인 후 프로필 메뉴 선택
2. "비밀번호 변경" 클릭
3. 현재 비밀번호 입력
4. 새 비밀번호 입력 및 확인
5. "변경하기" 버튼 클릭

### 2.4 로그아웃

1. 프로필 또는 메뉴에서 "로그아웃" 선택
2. 확인

## 3. 홈 화면

### 3.1 홈 화면 구성

로그인 후 표시되는 메인 화면입니다.

#### 3.1.1 상단 영역
- **타이어패스 로고**: 클릭시 홈으로 이동
- **검색 아이콘**: 상품 검색 화면으로 이동
- **프로필 아이콘**: 프로필 및 설정 메뉴

#### 3.1.2 상품 목록
- 타이어 상품 카드 형식으로 표시
- 스크롤하여 더 많은 상품 확인
- 각 상품 카드 정보:
  - 상품 이미지 (브랜드 로고)
  - 상품명
  - 브랜드
  - 공급가격
  - 할인가 (고객별 할인 적용시)
  - 재고 수량

#### 3.1.3 하단 네비게이션
- **홈**: 상품 목록 (현재 화면)
- **장바구니**: 담은 상품 확인
- **주문내역**: 주문 내역 조회
- **프로필**: 내 정보 및 설정

### 3.2 상품 카드 이해하기

각 상품 카드에 표시되는 정보:

```
[브랜드 로고]
상품명: 미쉐린 프라이머시 4 195/65R15
브랜드: 미쉐린
공급가: 150,000원
할인가: 135,000원 (10% 할인)
재고: 50개
```

**할인율 적용**:
- 고객님께 적용된 할인율이 자동 계산됩니다
- 브랜드별 할인, 상품별 할인이 모두 반영됩니다

## 4. 상품 검색 및 조회

### 4.1 상품 검색

#### 4.1.1 검색 방법
1. 상단의 검색 아이콘 클릭
2. 검색어 입력
   - 상품코드 (예: M-195/65R15)
   - 상품명 (예: 프라이머시)
   - 브랜드명 (예: 미쉐린)
3. 검색 결과 확인

#### 4.1.2 검색 필터 (있는 경우)
- 브랜드별 필터
- 가격 범위
- 재고 있음만 보기

### 4.2 상품 상세 정보

상품 카드를 클릭하면 상세 정보를 확인할 수 있습니다.

#### 4.2.1 상세 화면 구성
- **상품 이미지**: 브랜드 로고 또는 타이어 이미지
- **상품명**: 전체 상품명
- **상품코드**: 고유 상품 코드
- **브랜드**: 타이어 브랜드
- **공급가격**: 정상가
- **할인가**: 고객 할인가 (할인율 표시)
- **재고 수량**: 현재 재고
- **제조연도**: 타이어 제조연도 (있는 경우)

#### 4.2.2 성능 정보 (있는 경우)
- 연비 등급
- 소음 등급
- 접지력 등급
- 기타 성능 태그

#### 4.2.3 수량 선택
- "-" / "+" 버튼으로 수량 조절
- 직접 숫자 입력 가능
- 재고 수량 이내에서만 선택 가능

#### 4.2.4 장바구니 담기
- "장바구니 담기" 버튼 클릭
- 성공 메시지 확인
- "장바구니 보기" 또는 "계속 쇼핑하기" 선택

## 5. 장바구니

### 5.1 장바구니 접근

하단 네비게이션에서 "장바구니" 아이콘 클릭

### 5.2 장바구니 화면

#### 5.2.1 장바구니 상품 목록
각 상품마다 표시되는 정보:
- 상품 이미지
- 상품명
- 브랜드
- 단가 (할인가)
- 수량 조절 (-, +)
- 소계 금액
- 삭제 버튼 (X)

#### 5.2.2 수량 변경
- "-" / "+" 버튼으로 수량 조절
- 수량 변경시 금액 자동 업데이트
- 재고 수량 초과시 알림

#### 5.2.3 상품 삭제
- 상품 옆의 "X" 또는 "삭제" 버튼 클릭
- 확인 후 삭제

### 5.3 주문 금액 요약

장바구니 하단에 표시:
- **상품 금액**: 모든 상품의 합계
- **할인 금액**: 적용된 총 할인액
- **포인트 사용**: 사용할 포인트 (주문 단계에서 설정)
- **최종 결제 금액**: 실제 결제할 금액

### 5.4 주문하기

"주문하기" 버튼 클릭하여 결제 단계로 이동

## 6. 주문 및 결제

### 6.1 주문 정보 입력

#### 6.1.1 배송지 정보
- **기존 배송지 선택**: 등록된 배송지 목록에서 선택
- **새 배송지 입력**:
  - 수령인 이름
  - 연락처
  - 우편번호 (주소 검색)
  - 기본 주소
  - 상세 주소
  - 배송 메모 (선택)
  - "기본 배송지로 저장" 체크 (선택)

#### 6.1.2 주문 상품 확인
- 장바구니의 모든 상품 표시
- 각 상품의 수량, 단가, 합계 확인

#### 6.1.3 포인트 사용
- 현재 보유 포인트 표시
- 사용할 포인트 입력
- 최소 사용 포인트 확인
- 주문 금액 이내에서만 사용 가능

### 6.2 결제 수단 선택

토스페이먼츠 결제 위젯이 자동으로 표시되며, 다음 결제 수단을 선택할 수 있습니다:

#### 6.2.1 사용 가능한 결제 수단
- **신용카드/체크카드**: 카드 정보를 직접 입력하여 결제
- **간편결제**:
  - 카카오페이
  - 네이버페이
  - 토스페이
  - 페이코
  - 기타 토스페이먼츠 지원 간편결제
- **계좌이체** (제공되는 경우)
- **가상계좌** (제공되는 경우)

#### 6.2.2 간편결제 사용 (권장)
1. 결제 화면에서 원하는 간편결제 방식 선택 (예: 카카오페이)
2. 해당 간편결제 앱/서비스로 이동
3. 간편결제 서비스에 등록된 결제수단으로 결제
4. 다음 결제부터는 간편하게 이용 가능

**간편결제의 장점**:
- 매번 카드 정보를 입력할 필요 없음
- 빠르고 안전한 결제
- 간편결제 서비스의 포인트/할인 혜택 활용 가능

### 6.3 최종 결제 금액 확인

주문서 하단에 표시:
- **상품 금액**: 총 상품 금액
- **할인 금액**: 고객 할인액
- **포인트 사용**: 차감할 포인트
- **배송비**: 배송비 (있는 경우)
- **최종 결제 금액**: 실제 결제될 금액

### 6.4 결제하기

#### 6.4.1 결제 프로세스
1. **배송지 정보 입력**: 수령인, 연락처, 주소 입력
2. **결제 수단 선택**: 토스페이먼츠 결제 위젯에서 원하는 결제 방법 선택
3. **이용약관 동의**: 결제 관련 약관 동의 (자동 표시)
4. **"결제하기" 버튼 클릭**

#### 6.4.2 결제 인증
선택한 결제 수단에 따라 인증 진행:

- **신용카드/체크카드**:
  - 카드 정보 입력 (카드번호, 유효기간, CVC, 비밀번호 앞 2자리)
  - SMS 본인인증 또는 간편인증

- **간편결제** (카카오페이, 네이버페이 등):
  - 해당 서비스로 자동 이동
  - 간편결제 앱에서 지문/PIN/비밀번호 인증
  - 등록된 결제수단으로 자동 결제

#### 6.4.3 결제 완료
- **결제 성공시**:
  - 주문 완료 화면 표시
  - 주문번호 및 결제 내역 확인
  - 포인트 적립 예정 안내

- **결제 실패시**:
  - 오류 메시지 표시
  - 실패 사유 안내 (한도 초과, 인증 실패 등)
  - 다른 결제 수단으로 재시도 가능

### 6.5 주문 완료

#### 6.5.1 완료 화면 정보
- 주문번호
- 주문 일시
- 결제 금액
- 배송 정보
- 포인트 적립 예정 안내

#### 6.5.2 다음 단계
- "주문 내역 보기" 클릭하여 상세 확인
- "홈으로 이동" 클릭하여 계속 쇼핑

## 7. 주문 내역

### 7.1 주문 내역 접근

하단 네비게이션에서 "주문내역" 아이콘 클릭

### 7.2 주문 목록

#### 7.2.1 주문 카드 정보
각 주문마다 표시:
- **주문번호**: 고유 주문 번호
- **주문일시**: 주문한 날짜와 시간
- **주문상태**: 대기, 확인, 배송중, 완료, 취소
- **상품 정보**: 주문한 상품 요약 (첫 상품명 외 N건)
- **주문 금액**: 총 결제 금액

#### 7.2.2 주문 상태별 표시
- **대기(PENDING)**: 주문 접수 대기 중
- **확인(CONFIRMED)**: 주문이 확인됨
- **배송중(SHIPPING)**: 배송 진행 중
- **완료(COMPLETED)**: 배송 완료
- **취소(CANCELLED)**: 주문 취소됨

### 7.3 주문 상세 정보

주문 카드를 클릭하면 상세 정보 확인

#### 7.3.1 주문 정보
- 주문번호
- 주문일시
- 주문상태

#### 7.3.2 주문 상품 목록
각 상품마다:
- 상품 이미지
- 상품명
- 수량
- 단가
- 할인율
- 합계금액

#### 7.3.3 결제 정보
- 결제 수단 (카드 정보)
- 상품 금액
- 할인 금액
- 포인트 사용액
- 최종 결제 금액
- 결제 상태

#### 7.3.4 배송 정보
- 수령인
- 연락처
- 배송지 주소
- 배송 메모

### 7.4 주문 관련 작업

#### 7.4.1 재주문
1. 주문 상세 화면에서 "재주문" 버튼 클릭
2. 동일한 상품이 장바구니에 담김
3. 장바구니로 이동하여 주문 진행

#### 7.4.2 주문 취소
1. 주문 상세 화면에서 "주문 취소" 버튼 클릭
2. 취소 사유 선택 또는 입력
3. 확인 버튼 클릭
4. 취소 완료시:
   - 사용한 포인트 환급
   - 결제 금액 환불 진행 (카드 취소)

**주문 취소 가능 시점**:
- 주문 상태가 "배송중" 이전일 때만 가능
- 배송 시작 후에는 취소 불가

## 10. 간편결제 이용

### 10.1 간편결제란?

타이어패스는 별도의 카드 등록 없이 토스페이먼츠 결제 위젯을 통해 다양한 간편결제 서비스를 이용할 수 있습니다.

### 10.2 지원되는 간편결제

- **카카오페이**: 카카오톡에서 간편 결제
- **네이버페이**: 네이버 ID로 간편 결제
- **토스페이**: 토스 앱에서 간편 결제
- **페이코**: 페이코 앱에서 간편 결제
- **신용카드/체크카드**: 직접 카드 정보 입력
- **기타**: 토스페이먼츠가 지원하는 모든 결제 수단

### 10.3 간편결제 최초 사용

1. **주문/결제 화면에서 간편결제 선택**
   - 예: 카카오페이 선택

2. **간편결제 서비스로 이동**
   - 카카오톡 앱 자동 실행 (또는 웹페이지 이동)

3. **결제수단 등록 (최초 1회)**
   - 사용할 카드 등록
   - 본인인증 완료

4. **결제 완료**

### 10.4 두 번째 이용부터

간편결제 서비스에 이미 결제수단이 등록되어 있으므로:

1. 주문/결제 화면에서 간편결제 선택
2. 간편결제 앱에서 지문/PIN 인증만으로 결제 완료
3. 카드 정보 재입력 불필요

### 10.5 간편결제의 장점

- **빠른 결제**: 카드 번호 입력 없이 간편 인증만으로 결제
- **안전한 보안**: 카드 정보는 간편결제 서비스에서 안전하게 관리
- **추가 혜택**: 각 간편결제 서비스의 포인트/할인 혜택 활용
- **여러 카드 관리**: 간편결제 앱에서 여러 카드 등록 및 선택 가능

**주의**: 타이어패스는 결제수단을 별도로 저장하지 않습니다. 모든 결제는 토스페이먼츠와 선택한 간편결제 서비스를 통해 안전하게 처리됩니다.

## 11. 포인트

### 11.1 포인트 시스템 이해하기

#### 11.1.1 포인트란?
- 주문 완료시 자동으로 적립되는 보상 포인트
- 다음 주문시 현금처럼 사용 가능
- 1포인트 = 1원

#### 11.1.2 포인트 적립
- 주문 완료시 구매 금액의 일정 비율 적립
- 적립률: 관리자가 설정한 정책에 따름 (예: 1%)
- 적립 시점: 주문 상태가 "완료"로 변경될 때

#### 11.1.3 포인트 사용
- 주문시 보유 포인트 범위 내에서 사용
- 최소 사용 포인트: 정책에 따름 (예: 1,000포인트 이상)
- 주문 금액 이내에서만 사용 가능

#### 11.1.4 포인트 유효기간
- 적립일로부터 정해진 기간 동안 유효
- 유효기간: 관리자 정책에 따름 (예: 1년)
- 유효기간 지난 포인트는 자동 소멸

### 11.2 포인트 조회

#### 11.2.1 현재 포인트
- 프로필 화면 상단에 표시
- 사용 가능한 포인트 확인

#### 11.2.2 포인트 내역 보기
프로필 → 포인트 내역

**표시 정보**:
- 거래 일시
- 거래 유형 (적립, 사용, 조정, 만료, 환급)
- 포인트 금액 (+/-)
- 거래 전 잔액
- 거래 후 잔액
- 관련 주문 번호 (있는 경우)
- 메모

### 11.3 포인트 사용 예시

**시나리오**:
1. 보유 포인트: 5,000포인트
2. 주문 금액: 100,000원
3. 사용할 포인트: 3,000포인트 입력
4. 최종 결제 금액: 97,000원 (100,000 - 3,000)

## 13. 고객 지원

### 13.1 자주 묻는 질문 (FAQ)

#### Q1: 회원가입시 고객코드가 없으면 어떻게 하나요?
A: 관리자에게 문의하여 고객코드를 발급받으세요. 기존 거래 고객이 아닌 경우 신규 고객으로 등록이 필요합니다.

#### Q2: 할인가가 표시되지 않아요.
A: 고객별 할인율이 설정되지 않은 경우 할인가가 표시되지 않을 수 있습니다. 관리자에게 할인율 설정을 요청하세요.

#### Q3: 장바구니에 담은 상품이 사라졌어요.
A: 장바구니는 로그인 상태에서 저장됩니다. 로그아웃하거나 브라우저 데이터를 삭제하면 장바구니가 초기화될 수 있습니다.

#### Q4: 결제가 실패했어요.
A: 다음을 확인하세요:
- 카드 한도 확인
- 카드 유효기간 확인
- 인터넷 연결 상태 확인
- 토스페이먼츠 서비스 정상 작동 확인
그래도 실패하면 관리자에게 문의하세요.

#### Q5: 주문을 취소하고 싶어요.
A: 주문 내역에서 해당 주문을 선택한 후 "주문 취소" 버튼을 클릭하세요. 배송 시작 전에만 취소 가능합니다.

#### Q6: 포인트가 적립되지 않았어요.
A: 포인트는 주문 상태가 "완료"로 변경되어야 적립됩니다. 주문 상태를 확인하고, "완료"인데도 적립되지 않았다면 관리자에게 문의하세요.

#### Q7: 배송지를 잘못 입력했어요.
A: 배송 시작 전에는 관리자에게 연락하여 변경 요청하세요. 배송 시작 후에는 변경이 어려울 수 있습니다.

#### Q8: 재고가 없는 상품도 주문할 수 있나요?
A: 재고가 0인 상품은 장바구니에 담을 수 없습니다. 재고가 들어오면 주문 가능합니다.

## 14. 트러블슈팅

### 14.1 로그인 문제

**증상**: 로그인이 되지 않음

**해결 방법**:
1. 사용자 이름과 비밀번호 정확히 확인
2. Caps Lock 확인
3. 비밀번호 재설정 (관리자 문의)
4. 브라우저 캐시 삭제 후 재시도

### 14.2 결제 오류

**증상**: 결제 버튼 클릭시 오류 발생

**해결 방법**:
1. 인터넷 연결 확인
2. 결제수단 유효성 확인 (카드 한도, 유효기간)
3. 다른 결제수단으로 시도
4. 브라우저 팝업 차단 해제
5. 다른 브라우저로 시도

### 14.3 장바구니 오류

**증상**: 장바구니에 상품이 담기지 않음

**해결 방법**:
1. 로그인 상태 확인
2. 재고 수량 확인
3. 브라우저 새로고침
4. 캐시 삭제 후 재시도

### 14.4 화면 표시 문제

**증상**: 화면이 제대로 표시되지 않음

**해결 방법**:
1. 브라우저 최신 버전으로 업데이트
2. 브라우저 캐시 삭제
3. 다른 브라우저로 시도
4. 모바일 데이터/Wi-Fi 전환
