# ============================================
# PythonAnywhere 환경변수 설정 - 전체 코드
# ============================================
#
# 사용 방법:
# 1. PythonAnywhere 로그인 (https://www.pythonanywhere.com/)
# 2. Web 탭 클릭
# 3. Environment variables 섹션으로 스크롤
# 4. 아래 각 항목을 Name/Value에 입력하고 "Add new variable" 클릭
# 5. 모든 환경변수 추가 후 "Reload" 버튼 클릭
#
# ============================================

# --------------------------------------------
# 1. DEBUG (디버그 모드)
# --------------------------------------------
Name:  DEBUG
Value: False

설명: 운영 환경에서는 반드시 False로 설정


# --------------------------------------------
# 2. DJANGO_SECRET_KEY (Django 비밀 키)
# --------------------------------------------
Name:  DJANGO_SECRET_KEY
Value: <아래에서 생성된 키를 복사하여 붙여넣기>

** 새로운 SECRET_KEY 생성 방법 **

방법 1: 로컬 컴퓨터에서 생성
-------------------------------
# 명령 프롬프트(CMD) 또는 PowerShell에서 실행:
cd C:\Users\jmyang\Dropbox\1.0_tirepass
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"

# 출력된 키를 복사 (예시):
# django-insecure-abc123xyz456def789ghi012jkl345mno678pqr901stu234vwx567yza890


방법 2: 온라인에서 생성
-------------------------------
1. https://djecrety.ir/ 접속
2. "Generate" 버튼 클릭
3. 생성된 키 복사


예시 (실제로는 위에서 생성한 키 사용):
Name:  DJANGO_SECRET_KEY
Value: django-insecure-y8$k2#m9@p4n7&q1w5e3r6t0u2i4o8p6a5s7d9f1g3h5j7k9


# --------------------------------------------
# 3. TOSS_PAYMENTS_CLIENT_KEY (토스 클라이언트 키)
# --------------------------------------------
Name:  TOSS_PAYMENTS_CLIENT_KEY
Value: <토스페이먼츠 라이브 클라이언트 키>

** 토스페이먼츠 키 확인 방법 **
1. https://developers.tosspayments.com/ 로그인
2. 상단 메뉴 "내 개발정보" 클릭
3. "API 키" 메뉴 선택
4. "라이브 환경" 탭 클릭 (중요! 테스트 환경 아님)
5. "클라이언트 키" 복사 (live_ck_로 시작)

예시:
Name:  TOSS_PAYMENTS_CLIENT_KEY
Value: live_ck_Z61JOxRQVE5oY2A4bXk3


# --------------------------------------------
# 4. TOSS_PAYMENTS_SECRET_KEY (토스 시크릿 키)
# --------------------------------------------
Name:  TOSS_PAYMENTS_SECRET_KEY
Value: <토스페이먼츠 라이브 시크릿 키>

** 토스페이먼츠 시크릿 키 확인 **
1. 위와 동일한 페이지에서
2. "시크릿 키" 복사 (live_sk_로 시작)
3. ⚠️ 주의: 이 키는 절대 외부에 노출하지 마세요!

예시:
Name:  TOSS_PAYMENTS_SECRET_KEY
Value: live_sk_OyL7qZ5rQdJoWnA1bgYo3w2X9K6mN4pT


# --------------------------------------------
# 5. TOSS_PAYMENTS_SECURITY_KEY (토스 보안 키)
# --------------------------------------------
Name:  TOSS_PAYMENTS_SECURITY_KEY
Value: <토스페이먼츠 보안 키>

** 보안 키 확인 **
1. 같은 페이지에서 "보안 키" 항목 확인
2. 없으면 비워두기 (선택 사항)

예시 (있는 경우):
Name:  TOSS_PAYMENTS_SECURITY_KEY
Value: test_gsk_docs_OaPz8L5KdmQXkzRz3y47BMw6


# --------------------------------------------
# 6. ERP_SYNC_API_KEY (광주 ERP API 키)
# --------------------------------------------
Name:  ERP_SYNC_API_KEY
Value: <광주 ERP 서버와 약속한 API 키>

설명: 광주 ERP 서버에서 데이터를 전송할 때 인증에 사용
      광주 담당자와 협의한 API 키를 입력

예시:
Name:  ERP_SYNC_API_KEY
Value: erp_api_key_itire_gwangju_2024


# --------------------------------------------
# 7. ALLOWED_HOSTS (선택 사항)
# --------------------------------------------
Name:  ALLOWED_HOSTS
Value: tirepass.pythonanywhere.com,localhost,127.0.0.1

설명: 설정하지 않으면 기본값 사용
      여러 도메인은 쉼표(,)로 구분


# --------------------------------------------
# 8. CSRF_TRUSTED_ORIGINS (선택 사항)
# --------------------------------------------
Name:  CSRF_TRUSTED_ORIGINS
Value: https://tirepass.pythonanywhere.com,http://localhost:8000

설명: CSRF 보호를 위한 신뢰 도메인
      설정하지 않으면 기본값 사용


# ============================================
# 입력 완료 후 확인 사항
# ============================================

1. PythonAnywhere Web 탭에서 "Reload" 버튼 클릭 (초록색 큰 버튼)

2. Bash 콘솔에서 확인:
   cd ~/tirepass
   python manage.py shell

   # Python 셸에서:
   from django.conf import settings
   print("DEBUG:", settings.DEBUG)  # False가 출력되어야 함
   print("SECRET_KEY:", settings.SECRET_KEY[:20] + "...")  # 설정한 키의 앞 20자
   print("TOSS_CLIENT:", settings.TOSS_PAYMENTS_CLIENT_KEY[:20] + "...")
   print("TOSS_SECRET:", settings.TOSS_PAYMENTS_SECRET_KEY[:20] + "...")
   print("ERP_API_KEY:", settings.ERP_SYNC_API_KEY)
   exit()

3. 웹사이트 접속 확인:
   https://tirepass.pythonanywhere.com/

4. 에러가 있으면 Error log 확인:
   Web 탭 → Error log 링크 클릭


# ============================================
# 환경변수 요약 (복사하여 메모장에 보관)
# ============================================

환경변수 이름              | 설명
--------------------------|----------------------------------
DEBUG                     | False (운영 환경)
DJANGO_SECRET_KEY         | Django 비밀 키 (새로 생성)
TOSS_PAYMENTS_CLIENT_KEY  | 토스 클라이언트 키 (live_ck_)
TOSS_PAYMENTS_SECRET_KEY  | 토스 시크릿 키 (live_sk_)
TOSS_PAYMENTS_SECURITY_KEY| 토스 보안 키
ERP_SYNC_API_KEY          | 광주 ERP API 키
ALLOWED_HOSTS             | (선택) 허용 호스트
CSRF_TRUSTED_ORIGINS      | (선택) CSRF 신뢰 도메인

# ============================================
# 문제 해결
# ============================================

문제: 웹사이트가 "Something went wrong" 오류
해결: Error log 확인 → 환경변수 누락 확인 → Reload

문제: "TOSS_PAYMENTS_CLIENT_KEY는 환경변수로 설정해야 합니다!"
해결: 토스 환경변수 3개 모두 설정 후 Reload

문제: 결제가 작동하지 않음
해결: 토스 키가 "라이브 환경" 키인지 확인 (live_로 시작)

문제: 환경변수 변경이 적용 안 됨
해결: 반드시 "Reload" 버튼 클릭 필요
