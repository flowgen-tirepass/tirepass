## 📋 배포 전 필수 작업

### 1. PythonAnywhere 환경변수 설정 ⚠️ 필수

**참고 문서**: `docs/PythonAnywhere_환경변수_설정_가이드.md`

#### 설정 방법:
1. https://www.pythonanywhere.com/ 로그인
2. **Web** 탭 클릭
3. **Environment variables** 섹션으로 스크롤
4. 아래 환경변수를 하나씩 추가:

```bash
Name: DEBUG
Value: False

Name: DJANGO_SECRET_KEY
Value: <새로운-강력한-시크릿-키-생성>

Name: TOSS_PAYMENTS_CLIENT_KEY
Value: <토스페이먼츠-라이브-클라이언트-키>

Name: TOSS_PAYMENTS_SECRET_KEY
Value: <토스페이먼츠-라이브-시크릿-키>

Name: TOSS_PAYMENTS_SECURITY_KEY
Value: <토스페이먼츠-보안-키>

Name: ERP_SYNC_API_KEY
Value: <광주-ERP-API-키>
```

#### 시크릿 키 생성 방법:

**방법 1: 로컬에서 생성**
```bash
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```

**방법 2: 온라인 생성**
- https://djecrety.ir/ 접속
- "Generate" 클릭
- 생성된 키 복사

#### 토스페이먼츠 키 확인:
1. https://developers.tosspayments.com/ 로그인
2. 내 개발정보 → API 키
3. **라이브 환경** 탭 선택
4. 클라이언트 키 (live_ck_로 시작) 복사
5. 시크릿 키 (live_sk_로 시작) 복사

#### 설정 후:
- **"Reload"** 버튼 클릭 (웹 앱 재시작)

### 2. 마이그레이션 확인 및 적용

**참고 문서**: `docs/마이그레이션_확인_가이드.md`

#### PythonAnywhere Bash 콘솔에서:

```bash
# 1. 프로젝트 디렉토리로 이동
cd ~/tirepass

# 2. 가상환경 활성화 (필요한 경우)
source venv/bin/activate

# 3. 마이그레이션 상태 확인
python manage.py showmigrations

# 4. 미적용 마이그레이션이 있으면 적용
```

## 🚨 긴급 대응

### 문제 1: 사이트가 로드되지 않음

**확인 사항**:
1. PythonAnywhere Web 탭에서 웹 앱 상태 확인
2. Error log 확인
3. 환경변수 설정 확인
4. Reload 버튼 클릭

### 문제 2: 결제가 작동하지 않음

**확인 사항**:
1. 토스페이먼츠 키가 **라이브 환경** 키인지 확인 (live_ck_, live_sk_)
2. 테스트 키 (test_)는 운영 환경에서 작동 안 함
3. HTTPS 사용 확인 (http:// → https://)

### 문제 3: ERP 연동이 안 됨

**확인 사항**:
1. ERP_SYNC_API_KEY 환경변수 설정 확인
2. 광주 ERP 서버 상태 확인
3. Error log에서 연결 오류 확인

### 문제 4: 정적 파일(CSS/JS)이 로드 안 됨

**해결 방법**:
```bash
cd ~/tirepass
python manage.py collectstatic --noinput
# Web 탭 → Reload
```
