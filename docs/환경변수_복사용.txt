=====================================================
PythonAnywhere 환경변수 설정 - 복사용
=====================================================

📋 사용 방법:
1. 아래 각 섹션의 Name과 Value를 복사
2. PythonAnywhere Web 탭 → Environment variables
3. Name 입력 → Value 붙여넣기 → Add new variable
4. 모든 항목 추가 후 Reload

⚠️ 주의: xxxxx로 표시된 부분은 실제 값으로 교체!

🔍 확인 명령어 (PythonAnywhere Bash 콘솔):

cd ~/tirepass
python manage.py shell

# Python 셸에서:
from django.conf import settings
print("DEBUG:", settings.DEBUG)
print("SECRET_KEY:", settings.SECRET_KEY[:20] + "...")
print("TOSS_CLIENT:", settings.TOSS_PAYMENTS_CLIENT_KEY[:15] + "...")
print("TOSS_SECRET:", settings.TOSS_PAYMENTS_SECRET_KEY[:15] + "...")
print("ERP_KEY:", settings.ERP_SYNC_API_KEY)
exit()

=====================================================

🚨 문제 해결:

문제: "Something went wrong" 오류
해결: Error log 확인 → 환경변수 누락 확인 → Reload

문제: "환경변수로 설정해야 합니다" 오류
해결: 해당 환경변수 추가 → Reload

문제: 결제 안 됨
해결: 토스 키가 "라이브" 키인지 확인 (live_로 시작)
