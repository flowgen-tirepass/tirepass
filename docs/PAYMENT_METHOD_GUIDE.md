## 📌 결제 수단 등록이란?

TirePASS 모바일 앱에서 **미리 결제 수단을 등록**해두면, 타이어 주문 시 매번 카드번호를 입력하지 않고 **빠르게 결제**할 수 있습니다.

### ✅ 장점

| 항목 | 설명 |
|------|------|
| ⚡ **빠른 주문** | 카드번호 입력 없이 클릭 한 번으로 결제 |
| 🔒 **안전한 보안** | 카드번호는 저장되지 않고, 토스페이먼츠 보안 시스템으로 관리 |
| 📱 **편리한 관리** | 여러 카드 등록 가능, 기본 결제 수단 설정 |
| 🏦 **계좌이체 지원** | 카드 외에 계좌이체도 가능 |

## 🛡️ 보안 및 개인정보 보호

### 카드 정보는 어떻게 보호되나요?

TirePASS는 **PCI DSS** 국제 보안 인증을 받은 **토스페이먼츠**를 통해 결제를 처리합니다.

#### 🔐 보안 처리 방식

```
[고객이 카드 등록]
       ↓
[토스페이먼츠가 카드번호 암호화]
       ↓
[TirePASS에는 "빌링키"만 저장]
       ↓
[카드번호는 토스페이먼츠에만 보관]
```

**빌링키(Billing Key)란?**
- 카드번호 대신 사용하는 **안전한 코드**
- 예: `card_abc123def456` (실제 카드번호 노출 안 됨)
- 빌링키로 결제 시 → 토스페이먼츠가 실제 카드번호로 결제 처리

### 📊 저장되는 정보 vs 저장되지 않는 정보

| 저장되는 정보 | 저장되지 않는 정보 |
|--------------|-------------------|
| ✅ 카드 별칭 (예: "회사 카드") | ❌ 카드번호 (16자리) |
| ✅ 카드 뒤 4자리만 (예: **** 1234) | ❌ 유효기간 |
| ✅ 카드사 이름 (예: 신한카드) | ❌ CVC/CVV |
| ✅ 빌링키 (토큰) | ❌ 비밀번호 |

## 💳 등록 가능한 결제 수단

### 1️⃣ 신용/체크카드

#### 지원 카드사
- 국민, 신한, 삼성, 현대, 롯데, 하나, 우리, NH농협
- BC, KB국민, 씨티, 광주, 전북, 제주, 새마을, 신협 등
- **총 50개 이상 카드사 지원**

#### 등록 방법
1. **내정보 → 결제 수단 관리** 클릭
2. **카드 등록** 버튼 클릭
3. 카드 정보 입력 (2가지 방법)
   - 📸 **카드 스캔** (OCR 자동 인식) ← 편리!
   - ⌨️ 직접 입력
4. 본인 인증 (간편 비밀번호 또는 생체 인증)
5. 완료!

#### 📸 카드 스캔 기능 (OCR)

**스마트폰 카메라로 카드를 촬영하면 자동으로 정보 입력**

```
┌─────────────────────┐
│  📱 카메라로 촬영   │
│                     │
│   [신한카드 이미지]  │
│   1234 5678 9012    │
│   홍길동            │
│   12/25             │
└─────────────────────┘
         ↓
    AI가 자동 인식
         ↓
┌─────────────────────┐
│ ✅ 자동 입력 완료    │
│ 카드번호: 자동 입력  │
│ 유효기간: 자동 입력  │
│ 이름: 자동 입력      │
└─────────────────────┘
```

**장점:**
- ⚡ 입력 시간 **10초 이내**
- 🎯 입력 오류 **거의 0%**
- 📱 촬영만 하면 끝!

---

### 2️⃣ 계좌이체

#### 지원 은행
- 주요 시중은행 전체 지원
- 국민, 신한, 우리, 하나, 농협, 기업, SC제일, 씨티 등

#### 등록 방법
1. **내정보 → 결제 수단 관리**
2. **계좌 등록** 클릭
3. 은행 선택
4. 계좌번호 입력
5. 1원 인증 (은행에서 1원 입금 → 확인)
6. 완료!

## 🔧 관리 기능

### 등록한 결제 수단 관리

#### 기본 결제 수단 설정
- 자주 쓰는 카드를 **기본 결제 수단**으로 지정
- 주문 시 자동으로 선택됨

#### 여러 카드 등록
- 회사 카드, 개인 카드 등 **최대 10개** 등록 가능
- 별칭 지정: "회사 법인카드", "개인 신한카드" 등

#### 삭제
- 사용하지 않는 카드는 언제든지 삭제 가능
- 삭제 시 토스페이먼츠에서도 자동 삭제

## ❓ 자주 묻는 질문 (FAQ)

### Q1. 카드 정보가 유출될 위험은 없나요?
**A.** 카드번호는 TirePASS 서버에 저장되지 않습니다. 토스페이먼츠가 암호화하여 관리하므로 안전합니다.

### Q2. 등록한 카드로 자동 결제되나요?
**A.** 아니요. 주문 시 반드시 **결제 버튼을 클릭**해야 결제가 진행됩니다. 자동 결제는 되지 않습니다.

### Q3. 카드를 잃어버렸어요. 어떻게 하나요?
**A.** **내정보 → 결제 수단 관리**에서 해당 카드를 삭제하세요. 즉시 사용 중지됩니다.

### Q4. 카드 스캔이 안 될 때는?
**A.** 직접 입력 모드로 전환하여 수동으로 입력하실 수 있습니다.

### Q5. 법인카드도 등록 가능한가요?
**A.** 네, 가능합니다. 신용카드, 체크카드, 법인카드 모두 등록 가능합니다.

### Q6. 등록 수수료가 있나요?
**A.** 아니요. 카드/계좌 등록은 **무료**입니다.

### Q7. 계좌이체는 실시간 이체인가요?
**A.** 네, 실시간 계좌이체입니다. 주문 즉시 출금됩니다.
