## 1. 회원가입 및 로그인

### 1.1 회원가입

**[화면 캡처 위치: 회원가입 페이지]**

**접속 URL**: https://tirepass.pythonanywhere.com/mobile/signup/

**화면 구성**:
- 상단: TirePASS 로고 + "회원가입" 타이틀
- 중앙: 회원가입 폼
  - 사업자등록번호 (10자리, 하이픈 없이)
  - 상호명
  - 대표자명
  - 연락처1
  - 연락처3 (선택사항)
  - 비밀번호
  - 비밀번호 확인
- 하단: 회원가입 버튼

**작업 순서**:

**Step 1: 정보 입력**
1. **사업자등록번호** 입력
   - 10자리 숫자
   - 하이픈(-) 제외
   - 예: 123-45-67890 → `1234567890`
   - 실시간 유효성 검증 (10자리 확인)

2. **상호명** 입력
   - 사업자등록증상의 상호명
   - 예: `(주)플로우젠`, `ABC 카센터`

3. **대표자명** 입력
   - 대표자 성명
   - 예: `홍길동`

4. **연락처1** 입력
   - 주 연락처 (휴대폰 또는 사무실)
   - 하이픈 포함 가능
   - 예: `010-1234-5678` 또는 `01012345678`

5. **연락처3** 입력 (선택사항)
   - 추가 연락처
   - 비워두어도 가입 가능

6. **비밀번호** 입력
   - 최소 8자 이상
   - 영문 + 숫자 조합 권장
   - 특수문자 사용 가능

7. **비밀번호 확인** 재입력
   - 위에서 입력한 비밀번호와 동일하게 입력
   - 불일치 시 빨간색 에러 메시지 표시

**Step 2: 회원가입 완료**
1. "회원가입" 버튼 클릭
2. 입력 값 유효성 검증
   - 필수 항목 누락 시 에러 메시지
   - 사업자등록번호 중복 시 에러 메시지
3. 가입 성공 시 메시지 표시
   - "회원가입이 완료되었습니다"
   - "관리자 승인 후 로그인이 가능합니다"
4. 로그인 페이지로 자동 이동

**Step 3: 관리자 승인 대기**
- 관리자가 Admin 페이지에서 승인 처리
- 영업일 기준 1일 이내 승인
- 승인 완료 시 별도 연락

**주의사항**:
- 사업자등록번호는 이후 변경 불가능
- 비밀번호는 안전하게 보관
- 승인 전에는 로그인 불가

### 1.2 로그인

**[화면 캡처 위치: 로그인 페이지]**

**접속 URL**: https://tirepass.pythonanywhere.com/mobile/login/

**화면 구성**:
- 상단: TirePASS 로고
- 중앙: 로그인 폼
  - 사업자등록번호 입력창
  - 비밀번호 입력창
  - "로그인 유지" 체크박스
- 하단: 로그인 버튼, 회원가입 링크

**작업 순서**:

**Step 1: 로그인 정보 입력**
1. **사업자등록번호** 입력
   - 하이픈 없이 10자리
   - 회원가입 시 사용한 번호
2. **비밀번호** 입력
   - 회원가입 시 설정한 비밀번호
3. **로그인 유지** 체크 (선택사항)
   - 체크 시: 7일간 자동 로그인
   - 미체크 시: 브라우저 종료 시 로그아웃

**Step 2: 로그인 실행**
1. "로그인" 버튼 클릭
2. 인증 처리 (1~2초)
3. 성공 시 홈 화면으로 이동

**로그인 오류 처리**:

**"승인되지 않은 계정입니다"**
- 원인: 관리자 승인 대기 중
- 해결: 관리자에게 연락하여 승인 요청

**"사용자 이름 또는 비밀번호가 올바르지 않습니다"**
- 원인: 잘못된 사업자등록번호 또는 비밀번호
- 해결: 입력 내용 재확인
  - 사업자등록번호 10자리 확인
  - 하이픈 제거 확인
  - 비밀번호 대소문자 확인

**5회 이상 로그인 실패**
- 원인: 보안 잠금
- 해결: 관리자에게 연락하여 잠금 해제 요청

### 1.3 초기 로그인 후 비밀번호 변경 (선택사항)

**[화면 캡처 위치: 비밀번호 변경 안내]**

**작업 순서**:
1. 관리자가 "비밀번호 변경 필요" 플래그 설정 시
2. 로그인 후 비밀번호 변경 페이지로 자동 이동
3. 새 비밀번호 입력
4. 변경 완료 후 홈 화면 이동

## 2. 홈 화면

### 2.1 화면 구성

**[화면 캡처 위치: 홈 화면 전체]**

**상단 헤더**:
- 좌측: TirePASS 로고
- 중앙: "홈" 타이틀
- 우측: 알림 아이콘 (빨간 점: 새 알림)

**빠른 접근 메뉴** (카드 형식):
- 🔍 **상품 검색** (파란색 카드)
  - "원하는 타이어를 찾아보세요"
- 📋 **견적서 생성** (녹색 카드)
  - "고객 견적을 빠르게 만들기"
- 📦 **주문 내역** (주황색 카드)
  - "나의 주문을 확인하세요"
- 👤 **내 정보** (회색 카드)
  - "프로필 및 설정 관리"

**최근 본 상품** (스크롤 가능):
- 최근 조회한 상품 최대 10개
- 가로 스크롤 카드 형식
- 각 카드:
  - 브랜드 로고
  - 상품명 (1줄)
  - 할인가 (큰 글씨, 빨간색)
  - 재고 (작은 글씨, 회색)

**자주 주문하는 상품** (스크롤 가능):
- 주문 빈도 높은 상품 최대 5개
- 가로 스크롤 카드 형식
- "재주문" 버튼 포함

**공지사항** (최신 3개):
- 중요 공지 (빨간색 배지)
- 일반 공지
- "더보기" 링크

**하단 네비게이션 바**:
- 🏠 **홈**: 현재 페이지 (파란색 강조)
- 🛒 **상품**: 상품 목록
- 🛍️ **장바구니**: 장바구니 (빨간 배지: 개수)
- 📋 **주문내역**: 주문 목록
- 👤 **내정보**: 프로필

---

### 2.2 빠른 접근 메뉴 사용

**[화면 캡처 위치: 각 카드 클릭 시]**

**상품 검색 카드**:
- 클릭 시 → 상품 메뉴로 이동
- 검색창 자동 포커스

**견적서 생성 카드**:
- 클릭 시 → 견적 페이지로 이동
- 상품 선택부터 시작

**주문 내역 카드**:
- 클릭 시 → 주문 내역 페이지로 이동
- 최신 주문부터 표시

**내 정보 카드**:
- 클릭 시 → 프로필 페이지로 이동

---

### 2.3 최근 본 상품

**[화면 캡처 위치: 최근 본 상품 스크롤]**

**기능**:
- 최근 조회한 상품 자동 기록 (최대 10개)
- 가로 스크롤로 확인
- 카드 클릭 시 상품 상세 페이지로 이동

**카드 정보**:
- 브랜드 로고 (상단)
- 상품명 (중앙, 1줄 말줄임)
- 할인가 (하단, 빨간색 큰 글씨)
- 재고 (하단, 회색 작은 글씨)

## 3. 상품 검색 및 조회

### 3.1 상품 목록

**[화면 캡처 위치: 상품 목록 화면]**

**접근 방법**:
- 하단 네비게이션 바 → 상품 아이콘 클릭
- 홈 화면 → 상품 검색 카드 클릭

**화면 구성**:

**상단 검색 영역**:
- 검색창
  - 플레이스홀더: "상품명, 코드, 사이즈로 검색"
  - 우측: 🔍 검색 버튼
- 필터 버튼 (우측)
  - 🎛️ 아이콘 + "필터"

**필터 패널** (슬라이드인 패널):
- **브랜드 선택**
  - 체크박스 목록 (다중 선택 가능)
    - ☑️ 피렐리
    - ☐ 미쉐린
    - ☐ 굳이어
    - ... (15개 브랜드)
- **재고 상태**
  - ☐ 재고있는 상품만
- **정렬 기준**
  - ⚪ 최신순 (기본값)
  - ⚪ 가격 낮은순
  - ⚪ 가격 높은순
  - ⚪ 이름순
- 하단: "적용" 버튼, "초기화" 버튼

**상품 목록 (카드 형식)**:
- 무한 스크롤 (자동 로드)
- 각 카드 구성:
  - 좌측: 브랜드 로고 (정사각형)
  - 우측 상단:
    - 상품명 (2줄 말줄임)
    - 브랜드명 (회색 작은 글씨)
    - 상품코드 (회색 더 작은 글씨)
  - 우측 중앙:
    - 정가 (회색 취소선, 작은 글씨)
    - 할인가 (빨간색 큰 글씨 + 굵게)
  - 우측 하단:
    - 할인율 배지 (빨간색 배경, 흰색 글씨) "27% ↓"
    - 재고 (회색) "재고: 10개"
  - 카드 전체 클릭 가능

---

### 3.2 상품 검색

**[화면 캡처 위치: 검색 프로세스]**

**일반 검색**:

**Step 1: 검색어 입력**
1. 상단 검색창 클릭
2. 키워드 입력
   - 상품명: `P ZERO`
   - 상품코드: `P-PZERO-25`
   - 브랜드: `피렐리`
   - 타이어 사이즈: `255/40R20` 또는 `2554020`
3. 키보드의 "검색" 버튼 클릭 또는 🔍 버튼 클릭

**Step 2: 검색 결과 표시**
1. 로딩 스피너 (1~2초)
2. 검색 결과 목록 표시
3. 상단에 검색어 유지
4. 결과 개수 표시
   - "'P ZERO' 검색 결과 25개"

**Step 3: 추가 필터링 (선택사항)**
1. 필터 버튼 클릭
2. 브랜드 또는 재고 필터 선택
3. "적용" 버튼 클릭
4. 필터링된 결과 표시

**타이어 사이즈 검색 (특별 기능)**:

**숫자만 입력**:
1. 검색창에 `2554020` 입력
2. 시스템이 자동으로 변환
   - 입력: `2554020`
   - 변환: `255/40R20`, `255-40-20`, `255/40/20` 등
3. 모든 표기 형식을 자동 검색
4. 결과 표시

**슬래시 포함 입력**:
1. 검색창에 `255/40R20` 입력
2. 정확한 사이즈로 검색
3. 결과 표시

### 3.3 상품 상세

**[화면 캡처 위치: 상품 상세 전체 화면]**

**접근 방법**:
- 상품 목록에서 상품 카드 클릭

**화면 구성**:

**상단 헤더**:
- 좌측: ← 뒤로가기 버튼
- 중앙: "상품 상세" 타이틀
- 우측: ❤️ 찜하기 아이콘 (향후 기능)

**브랜드 로고 영역**:
- 중앙 정렬 브랜드 로고 (큰 사이즈)
- 예: 피렐리 로고, 미쉐린 로고

**상품 기본 정보 카드** (흰색 박스):
- **상품명** (큰 글씨, 굵게, 2줄 가능)
  - "피렐리 P ZERO 255/40R20 101Y XL *MOE RFT"
- **뱃지 영역** (가로 배치)
  - 🔷 "타이어" 배지 (파란색)
  - 🟢 "피렐리" 배지 (녹색)
  - 🔵 "재고: 10개" 배지 (파란색)

**가격 정보 카드** (회색 배경):
- **정가 (공장도가)**
  - 레이블: "공장도가" (작은 글씨, 회색)
  - 가격: "300,000원" (중간 글씨, 회색 취소선)
- **할인가 (매입가)**
  - 레이블: "매입가 (할인 적용)" (작은 글씨, 회색)
  - 가격: "219,000원" (큰 글씨, 파란색, 굵게)
- **할인율 상세 박스** (흰색 배경, 둥근 모서리)
  - 상단 행:
    - 좌측: "총 할인율" (중간 글씨, 굵게)
    - 우측: "27.0%" 배지 (빨간색 배경)
  - 하단 행:
    - "할인 상세 보기 ▼" 버튼 (파란색 텍스트)
  - **할인 상세 패널** (접혀있음, 클릭 시 펼침)
    - 구분선
    - 기본 할인: -20.0% (회색 → 빨간색)
    - 브랜드/그룹 할인: -4.0% (회색 → 빨간색)
    - 추가 할인: -0.0% (회색, 비활성)
    - DOT 할인: -3.0% (회색 → 빨간색)

**DOT 선택 카드** (흰색 박스, 표시 조건부):
- **레이블**: "제조년도 선택 (DOT)" (중간 글씨)
- **드롭다운 선택**
  - 기본값: "선택 안함"
  - 옵션:
    - "2024년 (재고: 4개, -3%)"
    - "2023년 (재고: 3개, -4%)"
    - "2022년 (재고: 2개, -5%)"
    - "2021년 이전 (재고: 1개, -10%)"
- **설명**: "제조년도를 선택하면 추가 할인이 적용됩니다" (작은 글씨, 회색)

**수량 선택 카드** (흰색 박스):
- **레이블**: "수량" (중간 글씨)
- **수량 조절**
  - 좌측: `-` 버튼 (원형, 회색 테두리)
  - 중앙: 수량 표시 (큰 글씨, 중앙 정렬) "4"
  - 우측: `+` 버튼 (원형, 파란색 테두리)
- **재고 표시**: "재고: 10개" (작은 글씨, 회색)

### 3.4 할인 상세 보기

**[화면 캡처 위치: 할인 상세 펼친 상태]**

**작업 순서**:
1. 가격 정보 카드에서 "할인 상세 보기 ▼" 버튼 클릭
2. 할인 상세 패널 펼침 (애니메이션)
3. 4가지 할인 내역 표시
   ```
   기본 할인        -20.0%
   브랜드/그룹 할인  -4.0%
   추가 할인        -0.0%
   DOT 할인         -3.0%
   ────────────────────
   총 할인율        27.0%
   ```
4. 버튼 텍스트 변경: "할인 상세 접기 ▲"
5. 다시 클릭 시 접힘

**할인 항목 설명**:
- **기본 할인**: 상품별 기본 할인율 (모든 고객 동일)
- **브랜드/그룹 할인**: 고객별 브랜드 그룹 할인율 (고객마다 다름)
- **추가 할인**: 특정 고객에게 특정 상품 추가 할인
- **DOT 할인**: 제조년도별 할인 (DOT 선택 시 적용)

**색상 코드**:
- 항목명: 회색
- 할인율:
  - 0%: 회색 (비활성)
  - >0%: 빨간색 (활성), 굵게

### 3.5 DOT 선택 및 가격 변동

**[화면 캡처 위치: DOT 선택 프로세스]**

**작업 순서**:

**Step 1: DOT 드롭다운 클릭**

   ```

   2024년 (재고: 4개, -3%)
   2023년 (재고: 3개, -4%)
   2022년 (재고: 2개, -5%)
   2021년 이전 (재고: 1개, -10%)
   ```

**Step 2: DOT 선택**
1. 원하는 연도 클릭 (예: "2023년 (재고: 3개, -4%)")

   - 변경: 216,000원 (DOT 4%)
2. 할인 상세 업데이트
   - DOT 할인: -3% → -4%
   - 총 할인율: 27% → 28%
3. 애니메이션 효과 (가격 깜빡임)

**주의사항**:
- DOT 선택 안 함 시: DOT 할인 0% 적용

### 5.6 마진율 조정 팁

**[화면 캡처 위치: 마진율 입력 및 결과 비교]**

**시나리오별 마진율**:

- 마진율: 15%
- 예: 매입가 219,000원 → 제안가 251,850원

**VIP 고객** (낮은 마진):
- 마진율: 10%
- 예: 매입가 219,000원 → 제안가 240,900원

**신규 고객** (공격적 가격):
- 마진율: 5%
- 예: 매입가 219,000원 → 제안가 229,950원

**경쟁 입찰** (최소 마진):
- 마진율: 3%
- 예: 매입가 219,000원 → 제안가 225,570원

**프로젝트 납품** (높은 마진):
- 마진율: 20%
- 예: 매입가 219,000원 → 제안가 262,800원

**활용 팁**:
- 다양한 마진율로 여러 견적 생성
- 고객 협상 시 즉시 재계산
- 경쟁사 가격 대비 조정

### 7.3 배송지 관리

**접근 방법**:
- 내 정보 → 배송지 관리 메뉴 클릭

**화면 구성**:

**배송지 목록**:
- 각 배송지 카드:
  - **상단 행**:
    - 좌측: "기본" 배지 (기본 배송지만)
    - 우측: ✎ 수정, 🗑️ 삭제 아이콘
  - **수령인**: 홍길동 (중간 글씨, 굵게)
  - **연락처**: 010-1234-5678
  - **주소**:
    - (12345) 서울시 강남구 테헤란로 123
    - ABC빌딩 4층

**하단 버튼**:
- "+ 새 배송지 추가" (전체 폭, 파란색 테두리)

**배송지 추가**:

**[화면 캡처 위치: 배송지 추가 폼]**

**작업 순서**:
1. "+ 새 배송지 추가" 버튼 클릭
2. 입력 폼 표시:
   - 수령인
   - 연락처
   - 우편번호 (검색 버튼)
   - 주소
   - 상세주소
   - "기본 배송지로 설정" 체크박스

3. 주소 검색 및 선택
4. 우편번호, 주소 자동 입력

## 8. 부록

### 8.1 자주 묻는 질문 (FAQ)

**Q1. 할인가가 다르게 표시돼요**
- 고객별로 할인율이 다릅니다.
- 관리자에게 문의하세요.

**Q2. DOT 선택이 안 돼요**
- 해당 상품의 DOT 정보가 없을 수 있습니다.
- 관리자에게 문의하세요.

**Q3. 주문 취소하고 싶어요**
- 주문 상세 → "주문 취소 요청" 버튼
- 관리자가 확인 후 처리합니다.

**Q4. 장바구니가 사라졌어요**
- 로그아웃 시에도 장바구니는 유지됩니다.
- 다시 로그인하면 복원됩니다.

**Q5. 견적서를 저장하고 싶어요**
- 인쇄 기능으로 PDF 저장 가능합니다.
- 브라우저 인쇄 → PDF로 저장 선택

### 8.2 화면 용어 설명

**정가 / 공장도가**:
- ERP 시스템의 기본 판매가
- 할인 적용 전 가격

**매입가 / 할인가**:
- 4단계 할인 적용 후 가격
- 고객이 구매하는 실제 가격

**제안가 / 견적가**:
- 매입가에 마진을 더한 가격
- 고객(카센터)이 최종 소비자에게 제시하는 가격

**DOT / 제조년도**:
- 타이어 제조 연도
- 오래된 제조년도일수록 추가 할인

**마진율**:
- 매입가 대비 추가 이익률
- 고객(카센터)의 이윤
