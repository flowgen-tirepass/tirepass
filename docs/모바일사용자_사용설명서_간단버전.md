# 타이어패스 모바일 간단 사용설명서

**버전**: 1.0 | **최종 업데이트**: 2024년 11월 20일

---

## 1. 시작하기

### 접속 방법
- 모바일 브라우저에서 `http://your-domain.com/mobile/` 접속
- "시작하기" 클릭

### 앱처럼 사용하기 (PWA)
1. 브라우저 메뉴 → "홈 화면에 추가"
2. 앱 아이콘으로 빠른 접속

---

## 2. 회원가입 및 로그인

### 회원가입
1. "회원가입" 클릭
2. 필수 정보 입력:
   - 고객코드 (관리자에게 받음)
   - 사용자 이름 (로그인 ID)
   - 비밀번호 (8자 이상)
   - 이메일, 연락처
3. 이용약관, 개인정보처리방침 동의
4. "가입하기" 클릭

### 로그인
1. 사용자 이름, 비밀번호 입력
2. "로그인" 클릭

### 비밀번호 변경
프로필 → 비밀번호 변경

---

## 3. 화면 구성

### 하단 네비게이션
- **홈**: 상품 목록
- **장바구니**: 담은 상품
- **주문내역**: 주문 조회
- **프로필**: 내 정보 및 설정

---

## 4. 상품 검색 및 주문

### 상품 찾기
1. 홈 화면에서 상품 목록 확인
2. 검색 아이콘으로 검색:
   - 상품코드, 상품명, 브랜드명

### 상품 정보
각 상품 카드에 표시:
- 상품명, 브랜드
- 공급가, 할인가 (고객별 할인 적용)
- 재고 수량

### 장바구니 담기
1. 상품 카드 클릭 → 상세 화면
2. 수량 선택 (-, + 버튼)
3. "장바구니 담기" 클릭

---

## 5. 장바구니 및 결제

### 장바구니 확인
1. 하단 "장바구니" 클릭
2. 상품 목록, 수량, 금액 확인
3. 수량 변경 또는 삭제 가능

### 주문하기
1. "주문하기" 버튼 클릭
2. 배송지 입력 또는 선택
3. 포인트 사용 (선택)
4. 결제수단 선택 (토스페이먼츠 결제 위젯):
   - 신용카드/체크카드
   - 간편결제 (카카오페이, 네이버페이, 토스페이 등)
   - 계좌이체/가상계좌
5. "결제하기" 클릭

### 결제 완료
- 주문번호, 주문일시 확인
- 포인트 적립 예정 안내

---

## 6. 주문 내역

### 주문 조회
하단 "주문내역" 클릭

### 주문 상태
- **대기**: 주문 접수 중
- **확인**: 주문 확인됨
- **배송중**: 배송 중
- **완료**: 배송 완료
- **취소**: 주문 취소됨

### 주문 상세
주문 클릭 → 상품, 결제, 배송 정보 확인

### 재주문
주문 상세 → "재주문" 클릭 → 동일 상품 장바구니 담김

### 주문 취소
주문 상세 → "주문 취소" 클릭 → 취소 사유 입력
- 배송 시작 전에만 가능
- 포인트 환급, 결제 환불 자동 처리

---

## 7. 프로필 및 설정

### 프로필 메뉴
- **배송지 관리**: 배송지 추가/수정/삭제
- **비밀번호 변경**: 비밀번호 수정
- **포인트 내역**: 적립/사용 내역
- **정책 및 약관**: 이용약관, 개인정보처리방침 등
- **로그아웃**

---

## 8. 배송지 관리

### 배송지 추가
프로필 → 배송지 관리 → "배송지 추가"
- 수령인, 연락처
- 우편번호, 주소, 상세주소
- "기본 배송지로 설정" (선택)

### 배송지 수정/삭제
목록에서 배송지 선택 → 수정 또는 삭제

---

## 9. 간편결제 이용

### 지원되는 결제 방법
- **간편결제**: 카카오페이, 네이버페이, 토스페이, 페이코
- **카드 결제**: 신용카드/체크카드 직접 입력
- **기타**: 계좌이체, 가상계좌 (제공되는 경우)

### 간편결제 사용법
1. 주문/결제 화면에서 원하는 간편결제 선택
2. 간편결제 앱으로 자동 이동
3. 지문/PIN 인증으로 간편 결제
4. 최초 1회만 카드 등록, 이후 간편 인증만으로 결제

**참고**: 타이어패스는 결제수단을 별도로 저장하지 않습니다. 모든 결제는 토스페이먼츠와 간편결제 서비스를 통해 안전하게 처리됩니다.

---

## 10. 포인트

### 포인트 적립
- 주문 완료시 자동 적립
- 적립률: 관리자 설정 (예: 1%)

### 포인트 사용
- 주문시 보유 포인트 입력
- 최소 사용 포인트 이상 사용
- 1포인트 = 1원

### 포인트 내역
프로필 → 포인트 내역
- 적립, 사용, 조정, 만료, 환급 내역 확인

---

## 11. 자주 묻는 질문

**Q: 할인가가 안 보여요**
A: 고객별 할인율이 설정되지 않았을 수 있습니다. 관리자에게 문의하세요.

**Q: 결제가 실패해요**
A: 카드 한도, 유효기간 확인 또는 다른 카드로 시도하세요.

**Q: 주문 취소는 어떻게 하나요?**
A: 주문 내역 → 주문 선택 → "주문 취소" (배송 시작 전에만 가능)

**Q: 포인트가 안 적립돼요**
A: 주문 상태가 "완료"여야 적립됩니다. 확인 후에도 문제시 관리자에게 문의하세요.

**Q: 재고가 없는 상품도 주문할 수 있나요?**
A: 재고 0인 상품은 장바구니에 담을 수 없습니다.

## 13. 보안 안내

- **비밀번호**: 8자 이상, 영문+숫자+특수문자 조합 권장
- **결제**: 토스페이먼츠 안전 결제 시스템
- **빌링키**: 카드 정보 암호화 저장, 실제 카드번호는 저장 안 됨
- **개인정보**: 안전하게 암호화되어 관리

## 14. 빠른 이용 가이드

### 처음 사용자
1. 회원가입 (고객코드 준비)
2. 로그인
3. 배송지 등록
4. 결제수단 등록 (빌링키)
5. 상품 검색 → 장바구니 → 주문

### 재구매 고객
1. 로그인
2. 주문 내역에서 이전 주문 확인
3. "재주문" 클릭
4. 장바구니에서 수량 조정
5. 주문하기
