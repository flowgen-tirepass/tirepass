## 1. 로그인 및 초기 화면

### 1.1 로그인 화면

**[화면 캡처 위치: 로그인 페이지]**

**접속 URL**: https://tirepass.pythonanywhere.com/admin/

**화면 구성**:
- 상단: TirePASS 로고
- 중앙: 로그인 폼
  - 사용자 이름 (관리자 계정)
  - 비밀번호
  - 로그인 버튼

**입력 방법**:
1. **사용자 이름**: Django 관리자 계정 입력
   - 예: `admin`, `staff_user`, `manager` 등
   - **슈퍼유저** 또는 **스태프** 권한이 있는 계정만 접속 가능
2. **비밀번호**: 해당 계정의 비밀번호 입력
3. **로그인** 버튼 클릭

**중요**:
- ❌ **사업자등록번호로는 관리자 페이지 접속 불가**
- ✅ 사업자등록번호는 모바일 페이지 고객 로그인용입니다.
- ✅ 관리자 페이지는 Django User 모델의 관리자 계정만 사용 가능합니다.

**주의사항**:
- 대소문자를 구분하므로 정확히 입력하세요.
- 관리자 계정은 시스템 관리자가 생성합니다.
- 5회 이상 로그인 실패 시 계정이 잠길 수 있습니다.

## 2. A. 판매 메뉴

### 2.1 상품 관리 (Goods)

**[화면 캡처 위치: 상품 관리 목록]**

#### 화면 구성
- **상단 필터 영역**
  - 검색창 (상품코드, 상품명, 브랜드 검색)
  - 필터 버튼 (타이어만, 재고있음)
- **우측 사이드바**
  - 브랜드 필터 (15개 브랜드)
- **중앙 목록**
  - 상품코드
  - 상품명
  - 브랜드 (BUN1)
  - 재고수량
  - 고정가격
  - 기본 할인율 (노란색 배지)
- **하단 페이지네이션**
  - 이전/다음 버튼
  - 페이지 번호
  - 총 상품 수 표시

#### 주요 기능

##### 1. 상품 검색

**[화면 캡처 위치: 검색창 및 검색 결과]**

**일반 검색**:
1. 상단 검색창에 키워드 입력
   - 상품코드: `P-PZERO-25`
   - 상품명: `피렐리 P ZERO`
   - 브랜드: `피렐리`
2. 엔터 또는 검색 버튼 클릭
3. 검색 결과 표시

**타이어 사이즈 검색** (특수 기능):
1. 검색창에 숫자만 입력
   - 예: `2355519` 입력
2. 시스템이 자동으로 `235/55R19` 형식으로 변환하여 검색
3. 다양한 표기 형식 모두 검색
   - `235/55R19`
   - `235/55/19`
   - `235-55-19`
   - `235 55 19`

**검색 결과**:
- 매칭되는 상품 목록 표시
- 검색어는 상단에 유지
- 필터와 함께 사용 가능

##### 2. 필터링

**[화면 캡처 위치: 필터 버튼 및 브랜드 사이드바]**

**타이어만 보기**:
1. 우측 "타이어 필터" 클릭
2. "타이어만" 체크
3. 타이어 상품만 표시 (2만개 → 약 1.5만개)

**재고있는 상품만**:
1. 우측 "재고 필터" 클릭
2. "재고있음" 체크
3. 재고 수량 > 0인 상품만 표시

**브랜드별 필터**:
1. 우측 "브랜드" 사이드바에서 브랜드 선택
   - 피렐리
   - 미쉐린
   - 굳이어
   - 한국
   - 금호
   - ... (15개 브랜드)
2. 선택한 브랜드 상품만 표시

**복합 필터**:
- 검색 + 필터 동시 사용 가능
- 예: "피렐리" 검색 + "재고있음" 필터
- 결과: 피렐리 브랜드 중 재고있는 상품만

##### 3. 기본 할인율 일괄 적용

**[화면 캡처 위치: 액션 선택 화면]**

**작업 순서**:
1. 상품 선택
   - 개별 선택: 각 상품 좌측 체크박스
   - 전체 선택: 목록 상단 "모두 선택" 체크박스
2. 액션 선택 드롭다운
   - "선택한 상품의 할인율을 22%로 설정"
   - "선택한 상품의 할인율을 25%로 설정"
   - "선택한 상품의 할인율을 30%로 설정"
3. "실행" 버튼 클릭
4. 확인 메시지 표시
   - "25% 적용 완료: 신규 X건, 수정 Y건"

**주의사항**:
- 기존 할인율은 덮어쓰기됩니다.
- YearAllocation 테이블에 저장됩니다.
- 되돌리기는 불가능하므로 신중히 선택하세요.

##### 4. 상품 상세 보기

**[화면 캡처 위치: 상품 상세 페이지]**

**접근 방법**:
- 상품 목록에서 상품코드 클릭

**화면 구성**:
- **기본 정보**
  - 상품코드 (읽기 전용)
  - 상품명
  - 브랜드
- **재고 및 가격**
  - 재고수량
  - 고정가격
- **시스템 정보** (접힌 상태)
  - 마지막 동기화 시간

**주의사항**:
- ERP 실시간 데이터이므로 수정 불가
- 조회만 가능

### 2.2 모바일 주문 (MobileOrder)

**[화면 캡처 위치: 모바일 주문 목록]**

#### 화면 구성
- **주문 목록**
  - 주문번호 (MOBILE-YYYY-NNN)
  - 고객명
  - 주문일시
  - 주문상태 (배지)
  - 결제상태 (배지)
  - 최종금액
  - 주문채널 (모바일)

#### 주요 기능

##### 1. 주문 목록 보기

**[화면 캡처 위치: 주문 목록 필터]**

**필터링**:
- 주문상태별: 접수, 처리중, 배송중, 완료, 취소
- 결제상태별: 대기, 완료, 취소, 환불
- 날짜별: 오늘, 이번 주, 이번 달

**검색**:
- 주문번호
- 고객명
- 연락처

**정렬**:
- 주문일시 (최신순/오래된순)
- 금액 (높은순/낮은순)

##### 2. 주문 상세 보기

**[화면 캡처 위치: 주문 상세 페이지]**

**접근 방법**:
- 주문 목록에서 주문번호 클릭

**화면 구성**:

**1) 주문 기본 정보**
- 주문번호
- 주문일시
- 주문채널
- 주문상태 (드롭다운으로 변경 가능)
- 결제상태

**2) 고객 정보**
- 고객코드
- 고객명
- 연락처
- 이메일

**3) 주문 항목 (인라인 표시)**
표 형식으로 표시:
| 상품코드 | 상품명 | 브랜드 | 수량 | DOT | 단가 | 할인율 | 할인가 | 최종가 |
|---------|-------|--------|------|-----|------|--------|--------|--------|
| P-PZERO-25 | 피렐리 P ZERO 255/40R20 | 피렐리 | 4 | 2024 | 300,000 | 27% | 219,000 | 876,000 |

하단 합계:
- 총 상품 수: X개
- 총 주문 금액: XXX,XXX원

**4) 결제 정보 (인라인 표시)**
- 결제수단
- 결제금액
- 결제상태
- 결제일시

**5) 배송 정보**
- 수령인
- 연락처
- 우편번호
- 주소
- 상세주소

##### 3. 주문 상태 변경

**[화면 캡처 위치: 주문 상태 드롭다운]**

**작업 순서**:
1. 주문 상세 페이지에서 "주문상태" 드롭다운 클릭
2. 상태 선택
   - **접수**: 주문 접수 완료
   - **처리중**: 상품 준비 중
   - **배송중**: 배송 시작
   - **완료**: 배송 완료
   - **취소**: 주문 취소
3. "저장" 버튼 클릭
4. 상태 변경 완료

**상태 변경 흐름**:
```
접수 → 처리중 → 배송중 → 완료
  ↓
취소 (어느 단계에서나 가능)
```

**주의사항**:
- 완료 상태에서는 취소 불가
- 취소 시 재고는 자동 복구되지 않음 (수동 처리)

### 2.3 ERP 전화 주문 (ERPPhoneOrder)

**[화면 캡처 위치: ERP 전화 주문 목록]**

#### 화면 구성
- 모바일 주문과 동일한 구조
- 주문번호 형식: `ERP-YYYY-NNN` 또는 `ERP-TEST-NNN`

#### 주요 기능

##### 1. 전화 주문 생성

**[화면 캡처 위치: 주문 생성 폼]**

**작업 순서**:
1. 우측 상단 "ERP 전화 주문 추가" 버튼 클릭
2. **주문 기본 정보 입력**
   - 고객: 드롭다운에서 선택 또는 검색
   - 주문채널: `erp_phone` (자동 설정)
   - 주문상태: 기본값 "접수"
3. **주문 항목 추가** (인라인 폼)
   - "주문 항목 추가" 버튼 클릭
   - 상품코드 입력 (ERP 조회하여 자동 완성)
   - 수량 입력
   - DOT 선택 (선택사항)
   - 할인율 자동 계산 및 표시
4. **배송 정보 입력**
   - 수령인, 연락처, 주소 입력
5. "저장" 버튼 클릭
6. 주문 생성 완료

**자동 처리 항목**:
- 주문번호: 자동 생성 (`ERP-2025-001` 형식)
- 할인율: 고객별 4단계 할인 자동 계산
- 최종가격: 자동 계산
- 주문일시: 현재 시각 자동 기록

##### 2. 수동 할인 조정

**[화면 캡처 위치: 주문 항목 할인율 수정]**

**작업 순서**:
1. 주문 상세 페이지에서 주문 항목의 "할인율" 클릭
2. 수동으로 할인율 입력
3. 최종가격 자동 재계산
4. "저장" 버튼 클릭

**주의사항**:
- 수동 할인율 적용 시 자동 계산 값은 무시됩니다.
- 수동 조정 이유를 메모에 기록하는 것이 좋습니다.

## 3. B. 할인 메뉴

### 3.1 브랜드 그룹 (BrandGroup)

**[화면 캡처 위치: 브랜드 그룹 목록]**

#### 화면 구성
- **목록**
  - ID
  - 브랜드 (파란색 텍스트)
  - 그룹명
  - 그룹순서 (직접 수정 가능)
  - 패턴 수 (파란색 숫자)
  - 패턴 미리보기 (회색 텍스트, 처음 3개 표시)
  - 활성화 (체크박스, 직접 수정 가능)
  - 생성일

#### 주요 기능

##### 1. 브랜드 그룹 생성

**[화면 캡처 위치: 브랜드 그룹 추가 폼]**

**작업 순서**:
1. 우측 상단 "브랜드 그룹 추가" 버튼 클릭
2. **기본 정보 입력**
   - 브랜드: 드롭다운 또는 직접 입력 (예: "피렐리")
   - 그룹명: 시리즈명 입력 (예: "P ZERO 시리즈")
   - 그룹순서: 표시 순서 (숫자, 낮을수록 먼저 표시)
   - 설명: 그룹 설명 (선택사항)
3. **패턴 목록 입력** (인라인 폼)
   - "패턴 추가" 버튼 클릭
   - 패턴 입력 (예: "P ZERO")
   - 여러 패턴 추가 가능
4. **상태 설정**
   - 활성화: 체크 (기본값)
5. "저장" 버튼 클릭
6. 그룹 생성 완료

**예시**:
- 브랜드: 피렐리
- 그룹명: P ZERO 시리즈
- 패턴:
  - P ZERO
  - P ZERO NERO
  - P ZERO ROSSO
  - P ZERO RUN FLAT

##### 2. 전체 고객 일괄 할인 적용 ⭐ (가장 중요!)

**[화면 캡처 위치: 액션 선택 → 중간 확인 페이지 → 결과 페이지]**

**작업 순서**:

**Step 1: 그룹 선택**
1. 브랜드 그룹 목록에서 할인 적용할 그룹 선택
   - 단일 선택: 한 개 그룹 체크
   - 다중 선택: 여러 그룹 체크 (예: 피렐리 전체 그룹)
2. 액션 드롭다운에서 "선택한 그룹의 할인율을 전체 고객에게 적용" 선택
3. "실행" 버튼 클릭

**Step 2: 중간 확인 페이지**

화면 구성:
- **제목**: "전체 고객에게 할인율 일괄 적용"
- **적용 대상 정보** (파란색 박스)
  - 선택한 그룹: X개
  - 활성 고객: Y명
  - 선택된 브랜드/그룹 목록 (파란색 박스)
- **주의사항** (노란색 박스)
  - Y명의 모든 활성 고객에게 할인율이 적용됩니다.
  - 이미 설정된 할인율이 있는 경우 덮어쓰기됩니다.
  - 총 X × Y = Z건의 할인 설정이 생성/수정됩니다.
  - 이 작업은 되돌릴 수 없으므로 신중하게 진행해주세요.
- **할인율 입력 폼** (녹색 박스)
  - 할인율 (%) 입력창
  - 0부터 100 사이, 소수점 2자리까지
- **버튼**
  - "할인율 적용" (녹색 버튼)
  - "취소" (회색 버튼)

**Step 3: 할인율 입력 및 적용**
1. 할인율 입력 (예: `4.00`)
2. "할인율 적용" 버튼 클릭
3. 처리 시작 (몇 초 ~ 몇 분 소요)

**Step 4: 결과 확인**
- 성공 메시지 (녹색 배경)
  - "4% 할인율 적용 완료: 신규 X건, 수정 Y건, 건너뜀 Z건"
- 브랜드 그룹 목록으로 자동 이동

**실제 예시**:
```
선택한 그룹: 3개 (피렐리 P ZERO 시리즈, CINTURATO 시리즈, SCORPION 시리즈)
활성 고객: 90명
할인율: 4%

결과: 신규 150건, 수정 120건, 건너뜀 0건
→ 90명 고객에게 3개 그룹별 4% 할인 적용 완료
```

**주의사항**:
- 되돌리기 불가능: 실행 전 반드시 확인
- 대량 처리: 고객 수가 많으면 시간이 소요됨 (1,000명 기준 약 1~2분)
- 덮어쓰기: 기존 할인율은 새 할인율로 완전히 대체됨

##### 3. 그룹 활성화/비활성화

**작업 방법**:
- 목록에서 직접 체크박스 클릭
- 하단 "저장" 버튼 클릭 (자동 저장)

**비활성화 시 효과**:
- 해당 그룹의 할인율은 적용되지 않음
- 고객할인 테이블에는 남아있지만 무시됨

##### 4. 그룹 복제

**[화면 캡처 위치: 액션 - 그룹 복제]**

**작업 순서**:
1. 복제할 그룹 선택 (하나만)
2. 액션: "선택한 그룹 복제 (패턴 포함)"
3. 실행
4. 복제본 생성 (그룹명에 " (복사본)" 추가)
5. 패턴도 모두 복제됨
6. 비활성 상태로 생성됨

**용도**:
- 유사한 그룹 빠르게 생성
- 테스트용 그룹 생성

##### 2. 패턴 작성 규칙

**좋은 예**:

- "PILOT SPORT" → "미쉐린 PILOT SPORT 4 225/45R18" 매칭
- "CINTURATO" → "피렐리 CINTURATO P7 205/55R16" 매칭

**나쁜 예**:
- "P" → 너무 많은 상품 매칭 (부적절)
- "255/40R20" → 사이즈는 그룹화 부적절
- "타이어" → 의미 없는 키워드

**팁**:
- 브랜드별 공식 시리즈명 사용
- 특수문자 포함 가능 (예: "N'FERA")
- 여러 패턴 조합으로 정확도 향상

##### 3. 패턴 삭제

**작업 방법**:
1. 패턴 목록에서 삭제할 패턴 선택
2. 액션: "선택한 패턴 삭제"
3. 실행
4. 확인 메시지에서 "예" 클릭

**주의사항**:
- 패턴 삭제 시 해당 패턴으로 적용된 할인은 유지됨
- 새로운 할인 적용 시 매칭되지 않음

  - 적용기간

#### 주요 기능

**필터링**:

4. 하단 "저장" 버튼 클릭

**대량 수정**:
1. 여러 할인율 수정
2. 한 번에 "저장" 버튼 클릭
3. 모든 변경사항 일괄 저장

##### 3. 적용 기간 설정

**[화면 캡처 위치: 고객 할인 상세 페이지]**

**작업 순서**:
1. 고객코드 클릭 (상세 페이지)
2. 할인 설정 섹션
   - 시작일: 날짜 선택 (선택사항)
   - 종료일: 날짜 선택 (선택사항)
3. "저장" 버튼 클릭

**적용 로직**:
- 시작일 전: 할인 미적용
- 기간 내: 할인 적용
- 종료일 후: 할인 미적용
- 기간 미설정: 무제한 적용

**용도**:
- 프로모션 할인
- 시즌 할인
- 계약 기간 할인

##### 4. 우선순위 관리

**작업 방법**:
- 목록에서 우선순위 칸 직접 수정
- 숫자가 낮을수록 우선 적용
- 같은 고객/브랜드에 여러 그룹이 있을 경우 우선순위 높은 것만 적용

**예시**:
```
고객: A 카센터
브랜드: 피렐리

그룹1: P ZERO 시리즈, 할인율 5%, 우선순위 1
그룹2: 전체 피렐리, 할인율 3%, 우선순위 2

→ P ZERO 상품: 5% 할인 적용 (우선순위 1)
→ 기타 피렐리: 3% 할인 적용 (우선순위 2)
```

  - 적용기간
  - 활성화 (체크박스)

#### 주요 기능

메모: VIP 고객 특별 할인
