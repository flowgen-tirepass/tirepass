# 타이어패스 관리자 페이지 간단 사용설명서

**버전**: 1.0 | **최종 업데이트**: 2024년 11월 20일

---

## 1. 로그인

**URL**: `http://your-domain.com/admin/`

관리자 계정으로 로그인

---

## 2. 주요 메뉴 설명

### 2.1 상품 관리 (Goods)

**메뉴 위치**: Tire_data → 상품

**주요 기능**:
- 상품 검색: 상품코드, 상품명으로 검색
- 필터: 타이어만 보기, 재고있음만 보기, 브랜드별 필터
- 실시간 ERP 연동: 조회시마다 최신 재고/가격 정보

**표시 정보**:
- 상품코드, 상품명, 브랜드(BUN1)
- 재고수량, 고정가격

**관련 메뉴**:
- **상품 디스플레이명**: 고객에게 보여질 사용자 정의 상품명 설정
- **제외 상품**: 모바일 앱에서 숨길 상품 지정

---

### 2.2 고객 관리 (Customers)

**메뉴 위치**: Tire_data → 고객

**주요 기능**:
- 고객 검색: 고객코드, 이름, 연락처로 검색
- 고객 상세: 기본정보, 할인정보, 포인트, 주문내역 확인
- 포인트 조정: 고객 포인트 수동 적립/차감

---

### 2.3 주문 관리 (Orders)

**메뉴 위치**: Tire_data → 주문

**주문 상태**:
- 대기(PENDING) → 확인(CONFIRMED) → 배송중(SHIPPING) → 완료(COMPLETED)
- 취소(CANCELLED)

**주요 작업**:
- 주문 상태 변경
- 주문 상세 조회: 상품목록, 결제정보, 배송정보
- 주문 취소: 취소 사유 입력 + 환불 처리

---

### 2.4 결제 관리 (Payments)

**메뉴 위치**: Tire_data → 결제

**결제(Payments)**:
- 결제 내역 조회
- 결제 상태: 완료, 대기, 실패, 취소
- 토스페이먼츠 연동 정보 확인

**결제 방식**:
- 간편결제: 카카오페이, 네이버페이, 토스페이, 페이코 등
- 카드 결제: 신용카드/체크카드 직접 입력
- 고객이 주문시 토스페이먼츠 결제 위젯에서 선택

**참고**: 시스템은 결제수단을 별도로 저장하지 않습니다. 모든 결제는 토스페이먼츠와 간편결제 서비스를 통해 안전하게 처리됩니다.

---

### 2.5 할인 관리

#### 연도별 할인 (Year Allocation)
**메뉴 위치**: Tire_data → 연도별 할인

타이어 제조연도에 따른 기본 할인율 설정
- 예: 2024년 → 10%, 2023년 → 15%

#### 고객 브랜드 할인 (Customer Brand Discount)
**메뉴 위치**: Tire_data → 고객 브랜드 할인

특정 고객에게 특정 브랜드 추가 할인 적용
- 고객 선택 → 브랜드 선택 → 할인율 입력

**일괄 적용**:
- 고객 목록에서 여러 고객 선택
- "브랜드 할인 일괄 적용" 액션 실행

#### 고객 상품 할인 (Customer Product Discount)
**메뉴 위치**: Tire_data → 고객 상품 할인

특정 고객에게 특정 상품 특별 할인 적용
- 가장 높은 우선순위

**할인 적용 순서**:
1. 연도별 기본 할인
2. 브랜드 할인 추가
3. 상품 할인 추가 (최우선)

---

### 2.6 포인트 관리

#### 포인트 정책 (Point Policy)
**메뉴 위치**: Tire_data → 포인트 정책

- 적립률 설정 (예: 1% = 100원당 1포인트)
- 최소/최대 사용 포인트
- 포인트 유효기간
- 활성화 여부

#### 고객 포인트 (Customer Point)
**메뉴 위치**: Tire_data → 고객 포인트

- 고객별 포인트 잔액 조회
- 총 적립/사용 포인트 확인

#### 포인트 거래 내역 (Point Transaction)
**메뉴 위치**: Tire_data → 포인트 거래 내역

모든 포인트 적립/사용 내역 조회
- 거래 유형: 적립, 사용, 조정, 만료, 환급

---

### 2.7 정책 페이지 관리 (Policy Page)

**메뉴 위치**: Tire_data → 정책 페이지

모바일 앱 정책 페이지 관리

**필수 페이지**:
- 이용약관 (terms-of-service)
- 개인정보처리방침 (privacy-policy)
- 환불정책 (refund-policy)

**설정 항목**:
- 제목, 슬러그(URL), 내용(HTML)
- 버전, 시행일, 활성화 여부

**모바일 표시**: `/mobile/policy/{슬러그}/`

---

### 2.8 배송지 관리 (Shipping Address)

**메뉴 위치**: Tire_data → 배송지 주소

- 고객별 배송지 주소 조회/수정
- 기본 배송지 설정
- 주소 활성화/비활성화

---

### 2.9 장바구니 (Shopping Cart)

**메뉴 위치**: Tire_data → 장바구니

고객별 장바구니 내역 조회
- 고객, 상품, 수량, 추가일시, 예상금액

---

### 2.10 브랜드 관리

#### 브랜드 (Brand)
**메뉴 위치**: Tire_data → 브랜드

브랜드 등록 및 관리
- 브랜드명, 코드, 로고, 설명, 원산지

#### 브랜드 패턴 (Brand Pattern)
**메뉴 위치**: Tire_data → 브랜드 패턴

ERP 데이터에서 브랜드 식별 패턴 등록
- 예: "미쉐린", "MICHELIN", "M-"

#### 브랜드 그룹 (Brand Group)
**메뉴 위치**: Tire_data → 브랜드 그룹

여러 브랜드를 그룹화하여 일괄 관리

---

### 2.11 성능 태그 관리

#### 성능 카테고리 (Performance Category)
**메뉴 위치**: Tire_data → 성능 카테고리

성능 분류 카테고리 설정
- 예: 연비, 소음, 접지력, 내구성, 제동력

#### 성능 태그 (Performance Tag)
**메뉴 위치**: Tire_data → 성능 태그

카테고리별 구체적 태그 등록

#### 상품 성능 태그 (Goods Performance Tag)
**메뉴 위치**: Tire_data → 상품 성능 태그

특정 상품에 성능 태그 연결 및 등급 부여

---

### 2.12 ERP 연동

#### ERP 스냅샷 (ERP Snapshot)
**메뉴 위치**: Tire_data → ERP 스냅샷

ERP 동기화 상태 및 내역 확인
- 마지막 동기화 시간, 상태, 오류 메시지

**동기화 방식**:
- 상품/고객 조회시 자동으로 실시간 ERP 연동

**API**:
- `/api/admin/erp/status/`: ERP 연결 상태
- `/api/admin/erp/reconnect/`: ERP 재연결

## 3. 빠른 작업 가이드

### 3.1 고객 할인율 설정하기

1. **브랜드 할인 적용**:
   - Tire_data → 고객 브랜드 할인 → 추가
   - 고객 선택 → 브랜드 선택 → 할인율 입력 → 저장

2. **상품 할인 적용**:
   - Tire_data → 고객 상품 할인 → 추가
   - 고객 선택 → 상품 선택 → 할인율 입력 → 저장

3. **일괄 할인 적용**:
   - Tire_data → 고객 → 대상 고객 선택(체크박스)
   - 작업 드롭다운 → "브랜드 할인 일괄 적용" → 실행

### 3.2 고객 포인트 조정하기

1. Tire_data → 고객 → 고객 선택
2. 고객 상세 페이지에서 "포인트 조정" 버튼
3. 조정 포인트 입력 (양수: 적립, 음수: 차감)
4. 조정 사유 입력 → 저장

### 3.3 주문 상태 변경하기

1. Tire_data → 주문 → 주문 선택
2. 주문 상세 페이지에서 상태 변경
3. 저장

### 3.4 정책 페이지 작성하기

1. Tire_data → 정책 페이지 → 추가
2. 제목, 슬러그, 내용 입력
3. 버전, 시행일 설정
4. 활성화 체크 → 저장

### 3.5 모바일에서 상품 숨기기

1. Tire_data → 제외 상품 → 추가
2. 상품 선택
3. 제외 사유 입력 (선택) → 저장

## 4. 모바일 앱 주요 URL

- `/mobile/`: 인트로
- `/mobile/home/`: 홈(상품목록)
- `/mobile/login/`: 로그인
- `/mobile/cart/`: 장바구니
- `/mobile/orders/`: 주문내역
- `/mobile/policy/{slug}/`: 정책페이지

## 5. 문제 해결

### ERP 연동 오류
- `/api/admin/erp/status/` 에서 상태 확인
- `/api/admin/erp/reconnect/` 로 재연결 시도

### 할인율 미적용
- 고객 할인 활성화 여부 확인
- 할인 적용 순서 확인 (연도 → 브랜드 → 상품)

### 포인트 미적립
- 포인트 정책 활성화 확인
- 주문 상태 확인 (완료 상태여야 적립)
