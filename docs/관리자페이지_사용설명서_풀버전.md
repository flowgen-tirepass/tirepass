## 1. 시스템 개요

### 1.1 시스템 구성
타이어패스는 Django 기반의 타이어 판매 관리 시스템으로 다음과 같이 구성됩니다:

- **관리자 페이지**: Django Admin을 기반으로 상품, 고객, 주문, 할인 등을 관리
- **모바일 웹**: 고객이 사용하는 모바일 웹 인터페이스
- **ERP 연동**: 실시간 ERP 시스템 연동을 통한 상품 및 재고 관리
- **결제 시스템**: 토스페이먼츠 연동을 통한 안전한 결제 처리

### 1.2 주요 기능
- **실시간 ERP 연동**: 상품, 재고, 가격 정보를 ERP 시스템과 실시간 동기화
- **고객별 할인 관리**: 브랜드별, 상품별, 연도별 다양한 할인 정책 적용
- **포인트 시스템**: 고객 포인트 적립 및 사용 관리
- **모바일 주문**: 모바일 앱을 통한 간편한 주문 및 결제
- **안전한 결제**: 토스페이먼츠를 통한 간편결제 및 카드 결제

## 2. 로그인 및 로그아웃

### 2.1 로그인
1. 관리자 페이지 URL 접속: `http://your-domain.com/admin/`
2. 관리자 계정 정보 입력
   - 사용자 이름
   - 비밀번호
3. "로그인" 버튼 클릭

### 2.2 로그아웃
1. 우측 상단 사용자 이름 클릭
2. "로그아웃" 선택
3. 자동으로 로그인 페이지로 리다이렉트

## 3. 대시보드

### 3.1 대시보드 접속
- 로그인 후 자동으로 표시되는 메인 화면
- 시스템의 주요 기능에 대한 빠른 접근 제공

### 3.2 대시보드 구성
- **상품(Goods)**: 타이어 및 관련 상품 관리
- **고객(Customers)**: 고객 정보 및 할인 정책 관리
- **주문(Orders)**: 주문 내역 조회 및 관리
- **결제(Payments)**: 결제 정보 조회 및 관리
- **할인(Discounts)**: 다양한 할인 정책 설정
- **포인트(Points)**: 포인트 적립 및 사용 관리
- **정책(Policies)**: 이용약관, 개인정보처리방침 등 정책 페이지 관리

## 4. 상품 관리

### 4.1 상품 목록 조회
**경로**: 대시보드 → Tire_data → 상품

#### 4.1.1 검색 기능
- **상품코드 검색**: 정확한 코드 또는 부분 일치 검색 가능
- **상품명 검색**: 상품명으로 검색
- **브랜드 검색**: BUN1 필드로 브랜드 검색

#### 4.1.2 필터 기능
1. **타이어 필터**: 타이어 상품만 표시
   - BUN1 브랜드명과 CODE 접두사 기반 필터링
   - 지원 브랜드: 한국, 금호, 넥센, 미쉐린, 브리지스톤, 콘티넨탈, 던롭, 굳이어, 피렐리, 요코하마, BFG, 하이로, 안나이트, 맥시스, 하이플라이

2. **재고 필터**: 재고가 있는 상품만 표시

3. **브랜드 필터**: 특정 브랜드의 상품만 표시

### 4.2 상품 상세 정보
상품 코드를 클릭하면 다음 정보를 확인할 수 있습니다:

#### 기본 정보
- **상품코드(CODE)**: 고유 상품 코드 (읽기 전용)
- **상품명(NAME)**: 상품의 전체 이름
- **브랜드(BUN1)**: 타이어 브랜드명

#### 재고 및 가격
- **재고수량(JAEGO)**: 현재 재고 수량 (천단위 콤마 표시)
- **고정가격(FIXP)**: 공급가격 (천단위 콤마 표시)

### 4.3 상품 디스플레이명 관리
**경로**: 대시보드 → Tire_data → 상품 디스플레이명

ERP 상품명 대신 고객에게 표시할 사용자 정의 상품명을 설정할 수 있습니다.

#### 설정 방법
1. "상품 디스플레이명 추가" 클릭
2. 상품 선택 (상품코드로 검색)
3. 표시할 이름 입력
4. 저장

### 4.4 제외 상품 관리
**경로**: 대시보드 → Tire_data → 제외 상품

모바일 앱에서 보이지 않도록 할 상품을 관리합니다.

#### 상품 제외하기
1. "제외 상품 추가" 클릭
2. 제외할 상품 선택
3. 제외 사유 입력 (선택사항)
4. 저장

## 5. 고객 관리

- 주소

- 포인트 잔액

고객 코드를 클릭하면 다음 정보를 확인/수정할 수 있습니다:

#### 기본 정보
- 고객코드
- 고객명
- 연락처
- 이메일
- 주소

#### 할인 정보
- 브랜드별 할인율
- 상품별 특별 할인율
- 연도별 할인 정책

#### 포인트 정보

- 포인트 적립/사용 내역

- 주문 번호
- 주문 일시
- 주문 금액
- 주문 상태

관리자가 직접 고객의 포인트를 조정할 수 있습니다.

#### 조정 방법
1. 고객 상세 페이지에서 "포인트 조정" 버튼 클릭
2. 조정할 포인트 입력 (양수: 적립, 음수: 차감)
3. 조정 사유 입력
4. 저장

## 6. 주문 관리

### 6.1 주문 목록 조회
**경로**: 대시보드 → Tire_data → 주문

#### 6.1.1 검색 기능
- **주문번호**: 주문 고유 번호로 검색
- **고객명**: 주문한 고객 이름으로 검색
- **주문일**: 특정 날짜 범위로 검색

#### 6.1.2 주문 상태
- **대기(PENDING)**: 주문 접수 대기
- **확인(CONFIRMED)**: 주문 확인 완료
- **배송중(SHIPPING)**: 배송 진행 중
- **완료(COMPLETED)**: 배송 완료
- **취소(CANCELLED)**: 주문 취소

### 6.2 주문 상세 정보
주문 번호를 클릭하면 다음 정보를 확인할 수 있습니다:

#### 주문 정보
- 주문번호
- 주문일시
- 주문 상태
- 고객 정보

#### 주문 상품 목록
- 상품코드
- 상품명
- 수량
- 단가
- 할인율
- 할인가
- 합계금액

#### 결제 정보
- 결제수단
- 결제상태
- 결제금액
- 포인트 사용액
- 최종 결제금액

#### 배송 정보
- 수령인
- 연락처
- 배송지 주소
- 배송 메모

### 6.3 주문 상태 변경
1. 주문 상세 페이지에서 주문 상태 선택
2. 상태 변경 사유 입력 (선택사항)
3. "저장" 클릭

### 6.4 주문 취소
1. 주문 상세 페이지에서 "주문 취소" 버튼 클릭
2. 취소 사유 입력
3. 환불 처리 방법 선택
   - 포인트 환급
   - 결제수단으로 환불
4. 확인

## 7. 결제 관리

### 7.1 결제 내역 조회
**경로**: 대시보드 → Tire_data → 결제

#### 7.1.1 검색 기능
- **결제키**: 토스페이먼츠 결제키로 검색
- **주문번호**: 연결된 주문번호로 검색
- **고객명**: 결제한 고객 이름으로 검색

#### 7.1.2 결제 상태
- **완료(COMPLETED)**: 결제 완료
- **대기(PENDING)**: 결제 대기
- **실패(FAILED)**: 결제 실패
- **취소(CANCELLED)**: 결제 취소

### 7.2 결제 방식 안내

타이어패스는 토스페이먼츠 결제 위젯을 통해 다양한 결제 수단을 지원합니다.

#### 7.2.1 지원되는 결제 방식
- **간편결제**: 카카오페이, 네이버페이, 토스페이, 페이코 등
- **신용카드/체크카드**: 직접 카드 정보 입력
- **기타**: 계좌이체, 가상계좌 (설정에 따라)

#### 7.2.2 결제 프로세스
1. 고객이 모바일에서 주문 생성
2. 토스페이먼츠 결제 위젯에서 결제 수단 선택
3. 선택한 방식으로 결제 진행 (간편결제 앱 또는 카드 인증)
4. 결제 승인 후 주문 상태 자동 업데이트

**참고**: 시스템은 결제수단을 별도로 저장하지 않습니다. 모든 결제는 토스페이먼츠를 통해 안전하게 처리되며, 간편결제 이용시 각 서비스(카카오페이 등)에서 결제수단을 관리합니다.

## 8. 할인 관리

### 8.1 연도별 할인 관리
**경로**: 대시보드 → Tire_data → 연도별 할인

타이어 제조연도에 따른 기본 할인율을 설정합니다.

#### 8.1.1 할인 정책 설정
1. "연도별 할인 추가" 클릭
2. 제조연도 입력 (예: 2024, 2023, 2022)
3. 기본 할인율 입력 (백분율, 예: 10 = 10%)
4. 저장

#### 8.1.2 할인율 적용 순서
1. 제조연도 확인
2. 해당 연도의 기본 할인율 적용
3. 고객별 추가 할인 적용 (브랜드별, 상품별)

### 8.2 브랜드 그룹 할인
**경로**: 대시보드 → Tire_data → 브랜드 그룹

여러 브랜드를 그룹화하여 일괄 할인율을 적용합니다.

#### 8.2.1 브랜드 그룹 생성
1. "브랜드 그룹 추가" 클릭
2. 그룹명 입력 (예: "프리미엄 브랜드")
3. 설명 입력
4. 저장

#### 8.2.2 브랜드 패턴 추가
1. 브랜드 그룹 선택
2. "브랜드 패턴 추가" 클릭
3. 브랜드명 또는 패턴 입력 (예: "미쉐린", "MICHELIN")
4. 저장

### 8.3 고객 브랜드 할인
**경로**: 대시보드 → Tire_data → 고객 브랜드 할인

특정 고객에게 특정 브랜드에 대한 추가 할인을 적용합니다.

#### 8.3.1 할인 설정 방법
1. "고객 브랜드 할인 추가" 클릭
2. 고객 선택
3. 브랜드 선택
4. 할인율 입력 (백분율)
5. 활성화 여부 선택
6. 저장

#### 8.3.2 일괄 할인 설정
여러 고객에게 동일한 브랜드 할인을 한번에 설정할 수 있습니다.

1. 고객 목록에서 대상 고객 선택 (체크박스)
2. "작업 선택" 드롭다운에서 "브랜드 할인 일괄 적용" 선택
3. 브랜드 및 할인율 입력
4. "실행" 클릭

### 8.4 고객 상품 할인
**경로**: 대시보드 → Tire_data → 고객 상품 할인

특정 고객에게 특정 상품에 대한 특별 할인을 적용합니다.

#### 8.4.1 할인 설정 방법
1. "고객 상품 할인 추가" 클릭
2. 고객 선택
3. 상품 선택 (상품코드로 검색)
4. 할인율 입력 (백분율)
5. 활성화 여부 선택
6. 저장

### 8.5 할인 적용 우선순위
최종 할인율은 다음 순서로 적용됩니다:

1. **기본 할인율**: 연도별 할인 (YearAllocation)
2. **브랜드 할인**: 고객별 브랜드 할인 추가
3. **상품 할인**: 고객별 상품 할인 추가 (가장 높은 우선순위)

예시:
- 2024년 타이어 기본 할인: 10%
- 고객 A의 미쉐린 브랜드 할인: +5%
- 고객 A의 특정 상품 할인: +3%
- 최종 할인율: 10% + 5% + 3% = 18%

## 9. 포인트 관리

### 9.1 포인트 정책 설정
**경로**: 대시보드 → Tire_data → 포인트 정책

포인트 적립 및 사용 규칙을 설정합니다.

#### 9.1.1 정책 항목
- **적립률**: 구매금액 대비 적립 비율 (예: 1% = 100원당 1포인트)
- **최소 사용 포인트**: 한번에 사용 가능한 최소 포인트
- **최대 사용 포인트**: 주문당 사용 가능한 최대 포인트
- **포인트 유효기간**: 적립 후 사용 가능한 기간 (일)
- **활성화 여부**: 포인트 시스템 사용 여부

#### 9.1.2 정책 설정 방법
1. "포인트 정책" 메뉴 선택
2. 기존 정책 수정 또는 새 정책 추가
3. 각 항목 입력

## 11. ERP 연동 관리

### 11.1 ERP 연동 개요
타이어패스는 실시간 ERP 시스템과 연동하여 상품 정보를 관리합니다.

#### 11.1.1 연동 데이터
- **상품 정보**: 상품코드, 상품명, 브랜드
- **재고 정보**: 실시간 재고 수량
- **가격 정보**: 공급가격
- **고객 정보**: 고객코드, 이름, 연락처, 주소

### 11.2 ERP 동기화 상태 확인
**경로**: 대시보드 → Tire_data → ERP 스냅샷

#### 11.2.1 상태 정보
- 마지막 동기화 시간
- 동기화 상태 (성공/실패)
- 동기화된 상품 수
- 오류 메시지 (있는 경우)

### 11.3 수동 동기화
관리자 페이지에서 상품 목록을 조회하면 자동으로 ERP와 동기화됩니다.

#### 11.3.1 상품 동기화
1. "상품" 메뉴 접속
2. 검색 또는 필터 적용
3. 자동으로 ERP에서 최신 데이터 조회
4. 결과 표시

#### 11.3.2 고객 동기화
1. "고객" 메뉴 접속
2. 고객 검색
3. 자동으로 ERP에서 최신 데이터 조회
4. 결과 표시

### 11.4 ERP 연동 API
**경로**: `/api/sync/`

#### 11.4.1 API 엔드포인트
- `POST /api/sync/customer/`: 고객 정보 동기화
- `POST /api/sync/goods/`: 상품 정보 동기화
- `GET /api/sync/status/`: 동기화 상태 조회

#### 11.4.2 ERP 상태 관리
- `GET /api/admin/erp/status/`: ERP 연결 상태 확인
- `POST /api/admin/erp/reconnect/`: ERP 재연결

## 19. 문제 해결 가이드

### 19.1 ERP 연동 오류
**증상**: 상품 정보가 표시되지 않음

**해결 방법**:
1. ERP 연결 상태 확인: `/api/admin/erp/status/`
2. ERP 재연결 시도: `/api/admin/erp/reconnect/`
3. 네트워크 연결 확인
4. ERP 서버 상태 확인

### 19.2 결제 오류
**증상**: 결제가 완료되지 않음

**해결 방법**:
1. 토스페이먼츠 API 키 확인
2. 결제 로그 확인
3. 결제수단(빌링키) 유효성 확인
4. 네트워크 연결 확인

### 19.3 할인율 미적용
**증상**: 고객별 할인율이 적용되지 않음

**해결 방법**:
1. 고객 브랜드 할인 활성화 여부 확인
2. 고객 상품 할인 활성화 여부 확인
3. 연도별 할인 설정 확인
4. 할인 적용 우선순위 확인

### 19.4 포인트 적립 오류
**증상**: 주문 완료 후 포인트가 적립되지 않음

**해결 방법**:
1. 포인트 정책 활성화 여부 확인
2. 포인트 적립률 설정 확인
3. 주문 상태 확인 (완료 상태여야 적립)
4. 포인트 거래 내역에서 오류 메시지 확인

## 22. 고객 지원

### 22.1 자주 묻는 질문 (FAQ)

**Q: 고객의 할인율을 어떻게 설정하나요?**
A: 고객 상세 페이지에서 브랜드별 또는 상품별 할인을 추가할 수 있습니다. 또는 고객 목록에서 여러 고객을 선택하여 일괄 할인을 적용할 수 있습니다.

**Q: ERP 데이터는 얼마나 자주 동기화되나요?**
A: 관리자 페이지에서 상품 또는 고객을 조회할 때마다 실시간으로 ERP 데이터를 가져옵니다.

**Q: 주문을 취소하면 포인트는 어떻게 되나요?**
A: 주문 취소시 사용된 포인트는 자동으로 환급되며, 적립된 포인트는 회수됩니다.

**Q: 모바일 앱에서 특정 상품을 숨기려면?**
A: "제외 상품" 메뉴에서 해당 상품을 추가하면 모바일 앱에서 보이지 않습니다.

### 22.2 기술 지원
기술적인 문제나 질문이 있을 경우:
- 이메일: support@tirepass.com

## 부록 A: 용어 정의

- **ERP**: Enterprise Resource Planning, 전사적 자원 관리 시스템
- **빌링키**: 고객의 결제수단을 안전하게 저장하여 재사용할 수 있는 토큰
- **할인율**: 백분율로 표시되는 할인 비율 (예: 10 = 10% 할인)
- **포인트**: 고객 충성도 보상 프로그램의 가상 화폐
- **슬러그(Slug)**: URL에 사용되는 고유 식별자 (예: "privacy-policy")

---

## 부록 B: API 엔드포인트 목록

### 관리자 API
- `POST /admin/adjust-points/<customer_id>/`: 고객 포인트 조정
- `GET /api/admin/erp/status/`: ERP 상태 확인
- `POST /api/admin/erp/reconnect/`: ERP 재연결

### 모바일 API
- `GET /api/mobile/products/`: 상품 목록 조회
- `POST /api/mobile/cart/add/`: 장바구니 추가
- `POST /api/mobile/orders/create/`: 주문 생성
- `POST /api/mobile/payment/billing/`: 빌링키 결제
- `GET /api/mobile/customer/info/`: 고객 정보 조회

### 동기화 API
- `POST /api/sync/customer/`: 고객 동기화
- `POST /api/sync/goods/`: 상품 동기화
- `GET /api/sync/status/`: 동기화 상태
