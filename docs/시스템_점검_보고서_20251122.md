### 6. 결제 시스템 점검

**상태**: ✅ 정상

**결제 시스템**: TossPayments v2 SDK

**구현 방식**:
```javascript
// mobile/templates/mobile/checkout.html (lines 479-549)
const tossPayments = await TossPayments(clientKey);
const paymentWidget = tossPayments.widgets({
    customerKey: '{{ customer.code }}'
});

await paymentWidget.renderPaymentMethods({
    selector: '#payment-widget',
    amount: { currency: 'KRW', value: finalAmount }
});

await paymentWidget.requestPayment({
    orderId: orderNumber,
    orderName: orderName,
    successUrl: window.location.origin + '/mobile/payment/success/',
    failUrl: window.location.origin + '/mobile/cart/'
});
```

**결제 흐름**:
1. 고객이 주문 생성 → Order, Payment 레코드 생성
2. TossPayments 위젯으로 결제 수단 선택 (간편결제, 카드)
3. 결제 성공 시 `/mobile/payment/success/` 리다이렉트
4. 서버에서 TossPayments API로 승인 요청
5. 승인 완료 시 Order 상태 업데이트 (confirmed, paid)
6. 포인트 적립 처리

**지원 결제 수단**:

- 기타: 계좌이체, 가상계좌 (제공되는 경우)
