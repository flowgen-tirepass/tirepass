■ 설치 방법 (5분)

  집 PC에서:

  ┌───────────────────────────────────────────────────────────────┐
  │ 1단계: 폴더 복사                                              │
  │                                                               │
  │   C:\Users\jmyang\Dropbox\1.0_tirepass\TgenAI_INSTALL\        │

  ┌───────────────────────────────────────────────────────────────┐
  │ 2단계: 자동 설치                                              │
  │                                                               │
  │   C:\TgenAI\install.bat 더블클릭                             │
  │                                                               │
  │   → 자동으로 설치됨:                                         │
  │     • Python 가상환경 생성                                   │
  │     • 필요한 패키지 설치                                     │
  │     • ERP DB 연결 테스트                                     │
  │     • FastAPI 서버 테스트                                    │
  └───────────────────────────────────────────────────────────────┘

  ┌───────────────────────────────────────────────────────────────┐
  │ 3단계: 자동 시작 등록                                         │
  │                                                               │
  │   C:\TgenAI\register_autostart.bat 우클릭                    │
  │   → "관리자 권한으로 실행" 선택                              │
  │                                                               │
  │   → Windows 작업 스케줄러에 등록됨                           │
  │   → PC 부팅 시 자동 시작                                     │
  └───────────────────────────────────────────────────────────────┘

■ 설치 확인

  1. 브라우저에서 접속:
     http://localhost:8002/health

     → 정상이면 다음과 같이 표시:
     {
       "status": "healthy",
       "database": "itire_db",
       "total_goods": 12345
     }

  2. PythonAnywhere 확인:
     https://tirepass.pythonanywhere.com/admin/tire_data/erpsnapshot/

     → 최신 스냅샷이 생성되는지 확인

■ 특징

  ✅ 완전 자동화: install.bat 한 번 실행으로 모든 설치 완료
  ✅ 자동 시작: PC 부팅 시 자동으로 시작
  ✅ 24/7 모니터링: 서버 다운 시 자동 재시작
  ✅ 광주 ERP와 독립적: 인터넷만 있으면 어디서든 가능
  ✅ 노트북 자유: 집 PC가 24/7 운영하므로 노트북 자유롭게 사용
