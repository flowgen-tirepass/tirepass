■ 빠른 설치 (5분)

┌─────────────────────────────────────────────────────────────────┐
│ [사전 준비]                                                     │
│                                                                 │
│ 1. Python 3.11 이상 설치 확인                                  │
│    → cmd에서 "python --version" 실행                          │
│    → 없으면 https://www.python.org/downloads/ 설치            │
│                                                                 │

┌─────────────────────────────────────────────────────────────────┐
│ [설치 단계]                                                     │
│                                                                 │
│ 1. 이 폴더 전체를 C:\TgenAI\ 로 복사                          │
│                                                                 │
│ 2. C:\TgenAI\install.bat 실행                                  │
│    → 모든 설치 자동 진행 (Python 환경, 패키지, DB 연결 등)    │
│                                                                 │
│ 3. C:\TgenAI\register_autostart.bat 우클릭                    │
│    → "관리자 권한으로 실행" 선택                               │
│    → 부팅 시 자동 시작 설정                                    │
└─────────────────────────────────────────────────────────────────┘

■ 설치 후 확인

  1. 브라우저에서 접속:
     http://localhost:8002/health

     → 다음과 같이 표시되면 정상:
     {
       "status": "healthy",
       "database": "itire_db",
       "total_goods": 12345
     }

  2. PythonAnywhere Admin:
     https://tirepass.pythonanywhere.com/admin/tire_data/erpsnapshot/

     → 최신 스냅샷이 생성되는지 확인

  3. 로그 확인:
     C:\TgenAI\tgenai_gateway_monitor.log

■ 문제 해결

  [문제] Python을 찾을 수 없음
  [해결] Python 재설치, "Add Python to PATH" 체크

  [문제] ERP DB 연결 실패
  [해결]
    - 인터넷 연결 확인
    - 광주 ERP 서버 상태 확인 (itire2.iptime.org)
    - 방화벽 설정 확인 (3306 포트)

  [문제] 포트 8002가 이미 사용 중
  [해결]
    cmd에서 실행:
    netstat -ano | findstr :8002
    taskkill /PID [프로세스ID] /F

  [문제] 자동 시작 등록 실패
  [해결] register_autostart.bat을 반드시 관리자 권한으로 실행
