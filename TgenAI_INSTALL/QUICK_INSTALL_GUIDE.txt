TgenAI PC 자동 복구 시스템 - 빠른 설치 가이드
================================================================================

이 폴더(TgenAI_INSTALL)의 모든 파일을 TgenAI PC의 C:\TgenAI\ 폴더로 복사하세요.

================================================================================
복사할 파일 (총 6개)
================================================================================

필수 파일:
  1. tgenai_erp_gateway_monitor.py        (ERP 게이트웨이 모니터)
  2. start_tgenai_gateway_monitor.bat     (모니터 시작)
  3. install_all_watchdogs.bat            (일괄 설치)
  4. teamviewer_watchdog.bat              (TeamViewer 감시)
  5. network_watchdog.bat                 (네트워크 감시)
  6. QUICK_INSTALL_GUIDE.txt              (이 파일)

================================================================================
설치 순서 (5분)
================================================================================

1. Python 패키지 설치
   ─────────────────────────────────────────────────────────────
   TgenAI PC에서 명령 프롬프트 열기:

   cd C:\TgenAI
   python -m pip install psutil requests

   성공 메시지 확인: "Successfully installed..."

2. 전체 시스템 설치
   ─────────────────────────────────────────────────────────────
   파일 탐색기에서:

   C:\TgenAI\install_all_watchdogs.bat

   우클릭 → "관리자 권한으로 실행"

   3개 작업 등록 완료 메시지 확인

3. 시스템 재부팅
   ─────────────────────────────────────────────────────────────
   시작 메뉴 → 전원 → 다시 시작

4. 재부팅 후 확인 (2-3분 대기)
   ─────────────────────────────────────────────────────────────
   로그 파일 생성 확인:

   C:\TgenAI\tgenai_gateway_monitor.log
   C:\TgenAI\teamviewer_watchdog.log
   C:\TgenAI\network_watchdog.log

5. ERP API 서버 확인
   ─────────────────────────────────────────────────────────────
   브라우저에서 접속:

   http://localhost:8000/health

   출력 확인:
   {"status":"healthy","database":"connected","total_goods":6530}

================================================================================
문제 발생 시
================================================================================

1. pip 명령어 실패
   → python -m pip install psutil requests

2. 작업 스케줄러 등록 실패
   → 관리자 권한으로 실행했는지 확인

3. 로그 파일 생성 안 됨
   → 작업 스케줄러 열기 (taskschd.msc)
   → 작업 우클릭 → "실행"
