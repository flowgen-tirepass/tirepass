================================================================================
TgenAI Wake-on-LAN 현장 설치 가이드 (5분)
================================================================================

광주 본사 방문 시 TgenAI PC에서 수행할 작업

================================================================================
준비물
================================================================================

□ 노트북 (이 파일 포함)
□ USB 메모리 (선택사항)

================================================================================
1단계: MAC 주소 확인 (1분)
================================================================================

TgenAI PC 명령 프롬프트에서:

  cmd
  getmac /v /fo list

이더넷 어댑터의 물리적 주소를 메모:
예: 1C-69-7A-12-34-56

→ 이 값을 노트북의 wake_tgenai.py 파일에 입력

================================================================================
2단계: BIOS Wake-on-LAN 설정 (2분)
================================================================================

1. TgenAI PC 재부팅
2. 부팅 중 F2 또는 DEL 키 연타 (제조사마다 다름)
3. BIOS 진입

BIOS 메뉴에서 찾기:
  - Advanced → Power Management
  - 또는 Boot → Wake on LAN
  - 또는 Integrated Peripherals

설정:
  ☑ Wake on LAN: Enabled
  ☑ Wake on PCIe/PCI: Enabled

4. F10 키 → Save and Exit

================================================================================
3단계: Windows 네트워크 어댑터 설정 (1분)
================================================================================

1. Win + X → 장치 관리자
2. 네트워크 어댑터 → 이더넷 어댑터 우클릭 → 속성
3. "전원 관리" 탭:
   ☑ 이 장치를 사용하여 컴퓨터의 대기 모드 해제 허용
   ☑ Magic Packet에서만 컴퓨터의 대기 모드 해제 허용
4. "고급" 탭:
   Wake on Magic Packet: Enabled
   Wake on pattern match: Enabled

5. 확인

================================================================================
4단계: 라우터 포트 포워딩 (1분)
================================================================================

공유기 관리 페이지 접속:
  http://192.168.0.1 (또는 공유기 IP)

설정:
  포트 포워딩 → 새 규칙 추가
  - 프로토콜: UDP
  - 외부 포트: 9
  - 내부 IP: TgenAI PC의 IP (예: 192.168.0.100)
  - 내부 포트: 9
  - 설명: TgenAI Wake-on-LAN

저장

================================================================================
5단계: 테스트 (선택사항)
================================================================================

TgenAI PC를 종료:
  shutdown /s /t 0

노트북에서 Magic Packet 전송:
  venv\Scripts\python.exe wake_tgenai.py

30초 후 TgenAI PC 전원 확인

================================================================================
완료 체크리스트
================================================================================

□ MAC 주소 확인 및 wake_tgenai.py 업데이트
□ BIOS Wake-on-LAN 활성화
□ Windows 네트워크 어댑터 전원 관리 설정
□ 공유기 포트 포워딩 (UDP 9)
□ 테스트 성공
